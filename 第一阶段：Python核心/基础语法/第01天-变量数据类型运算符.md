## 学习目标

---

## 1. 变量

### 变量定义

Python 是动态类型语言，变量不需要声明类型，直接赋值即可：

```python
name = "Alice"          # 字符串
age = 25                # 整数
height = 1.75           # 浮点数
is_student = True       # 布尔值
```

### 变量命名规则

- 必须以字母或下划线开头，不能以数字开头
- 只能包含字母、数字、下划线
- 区分大小写
- 不能使用 Python 关键字

```python
# 合法变量名
user_name = "Bob"
_count = 10
age2 = 30

# 非法变量名
# 2name = "Tom"      # 不能以数字开头
# user-name = "Bob"   # 不能使用连字符
```

### 多变量赋值

```python
# 链式赋值
a = b = c = 0          # a, b, c 都为 0

# 多元赋值
x, y = 10, 20          # x=10, y=20

# 交换变量
a, b = b, a            # 交换 a 和 b 的值
```

## 2. 基本数据类型

### 整数 (int)

```python
a = 100
b = -50
c = 0xFF               # 十六进制 255
d = 0b1010             # 二进制 10
```

### 浮点数 (float)

```python
pi = 3.14159
scientific = 1.5e-3     # 科学计数法 0.0015
```

### 字符串 (str)

```python
# 单引号
name = 'Alice'

# 双引号
name = "Alice"

# 三引号（多行字符串）
poem = '''
床前明月光，
疑是地上霜。
'''

# 字符串拼接
greeting = "Hello, " + name + "!"

# 字符串重复
line = "-" * 20        # "--------------------"

# 字符串索引
s = "Python"
print(s[0])            # "P"
print(s[-1])           # "n"

# 字符串切片
print(s[0:3])          # "Pyt"
print(s[2:])           # "thon"
print(s[:4])           # "Pyth"
```

### 布尔值 (bool)

```python
is_active = True
is_deleted = False

# 布尔转换
bool(1)                # True
bool(0)                # False
bool("")               # False
bool("hello")          # True
```

### 类型转换

```python
# 转换为整数
int("123")             # 123
int(3.14)              # 3

# 转换为浮点数
float("3.14")          # 3.14
float(100)              # 100.0

# 转换为字符串
str(123)               # "123"
str(3.14)              # "3.14"

# 转换为布尔值
bool(0)                # False
bool(1)                # True
bool("")               # False
bool("abc")            # True
```

## 3. 运算符

### 算术运算符

```python
a, b = 10, 3

print(a + b)           # 13  加
print(a - b)           # 7   减
print(a * b)           # 30  乘
print(a / b)           # 3.333...  除
print(a // b)          # 3   整除
print(a % b)           # 1   取余
print(a ** b)          # 1000 幂
```

### 比较运算符

```python
a, b = 10, 20

print(a == b)          # False  等于
print(a != b)          # True   不等于
print(a < b)           # True   小于
print(a > b)           # False  大于
print(a <= b)          # True   小于等于
print(a >= b)          # False  大于等于
```

### 赋值运算符

```python
a = 10

a += 5                # a = a + 5  => a = 15
a -= 3                # a = a - 3  => a = 12
a *= 2                # a = a * 2  => a = 24
a /= 4                # a = a / 4  => a = 6.0
a //= 2               # a = a // 2 => a = 3.0
a %= 2                # a = a % 2  => a = 1.0
a **= 3               # a = a ** 3 => a = 1.0
```

### 逻辑运算符

```python
x, y = True, False

print(x and y)         # False  逻辑与
print(x or y)         # True   逻辑或
print(not x)          # False  逻辑非
```

### 成员运算符

```python
fruits = ["apple", "banana", "orange"]

print("apple" in fruits)         # True
print("grape" not in fruits)     # True
```

### 身份运算符

```python
a = [1, 2, 3]
b = a
c = [1, 2, 3]

print(a is b)           # True   a 和 b 是同一对象
print(a is c)           # False  a 和 c 不是同一对象
print(a is not c)       # True
```

### 运算符优先级（从高到低）

1. `**` 幂运算
2. `* / // %` 乘除取余
3. `+ -` 加减
4. `== != > < >= <=` 比较
5. `not` 逻辑非
6. `and` 逻辑与
7. `or` 逻辑或

## 4. 格式化输出

### f-string（推荐）

```python
name = "Alice"
age = 25
height = 1.75

print(f"姓名: {name}, 年龄: {age}, 身高: {height}")
print(f"明年年龄: {age + 1}")
```

### format 方法

```python
print("姓名: {}, 年龄: {}".format(name, age))
print("姓名: {0}, 年龄: {1}, 姓名: {0}".format(name, age))
print("姓名: {n}, 年龄: {a}".format(n=name, a=age))
```

### 传统占位符

```python
print("姓名: %s, 年龄: %d" % (name, age))
```

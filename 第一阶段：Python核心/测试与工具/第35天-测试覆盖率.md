## 1. 什么是测试覆盖率

覆盖率衡量你的测试代码**执行了多少比例的源代码**。

常见类型：

| 类型 | 含义 |
|------|------|
| **行覆盖率** | 执行了多少行代码 |
| **分支覆盖率** | 执行了多少 if/else 分支 |
| **函数覆盖率** | 测试了多少函数 |

⚠️ **注意**：高覆盖率 ≠ 代码质量好。100% 覆盖率的代码仍可能有 bug。

## 2. coverage.py

### 安装

```bash
pip install coverage
# 或
pip install pytest-cov
```

### 基本用法

```bash
# 运行测试并收集覆盖率数据
coverage run -m pytest

# 生成终端报告
coverage report

# 生成 HTML 报告
coverage html
# 然后打开 htmlcov/index.html

# 生成 XML 报告（CI 工具用）
coverage xml
```

### 配置 .coveragerc

```ini
[run]
source = src
omit =
    */tests/*
    */venv/*
    */__pycache__/*
    src/main.py

[report]
exclude_lines =
    pragma: no cover
    def __repr__
    raise NotImplementedError
    if __name__ == .__main__.:

show_missing = True
skip_covered = False

[html]
directory = htmlcov
```

## 3. pytest-cov

### 用法

```bash
# 基本用法
pytest --cov=src

# 显示未覆盖的行
pytest --cov=src --cov-report=term-missing

# 生成 HTML 报告
pytest --cov=src --cov-report=html

# 设置覆盖率阈值（低于则失败）
pytest --cov=src --cov-fail-under=80

# 只显示未覆盖的
pytest --cov=src --cov-report=term-missing --cov-report=html
```

### pyproject.toml 配置

```toml
[tool.coverage.run]
source = ["src"]
omit = ["*/tests/*", "*/main.py"]

[tool.coverage.report]
exclude_lines = [
    "pragma: no cover",
    "def __repr__",
    "raise NotImplementedError",
]
fail_under = 80
show_missing = true

[tool.coverage.html]
directory = "htmlcov"
```

## 4. 阅读覆盖率报告

```
Name                      Stmts   Miss  Cover   Missing
-------------------------------------------------------
src/calculator.py            15      2    87%   12-13
src/utils.py                 10      0   100%
-------------------------------------------------------
TOTAL                        25      2    92%
```

- **Stmts**: 语句总数
- **Miss**: 未执行的语句
- **Cover**: 覆盖率百分比
- **Missing**: 未执行的行号

## 5. 实际例子

```python
# src/calculator.py
def divide(a, b):
    if b == 0:
        raise ValueError("Cannot divide by zero")
    return a / b

def calculate_stats(numbers):
    if not numbers:
        return None

    total = sum(numbers)
    avg = total / len(numbers)

    # pragma: no cover 表示这行不测
    if len(numbers) > 1000:  # pragma: no cover
        print("Large dataset")  # pragma: no cover

    return {"total": total, "average": avg}
```

## 实战练习

### 练习：为已有代码补全测试

```python
# src/discount.py
def apply_discount(price, discount_code):
    """应用折扣码"""
    if price <= 0:
        raise ValueError("Price must be positive")

    discounts = {
        "SAVE10": 0.10,
        "SAVE20": 0.20,
        "HALF": 0.50,
    }

    if discount_code in discounts:
        discount = discounts[discount_code]
        return round(price * (1 - discount), 2)

    return price
```

任务：
1. 编写测试，覆盖所有分支
2. 运行 `pytest --cov=src --cov-report=term-missing`
3. 确保覆盖率达到 100%

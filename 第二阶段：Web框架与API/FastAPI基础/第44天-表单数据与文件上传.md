## 2. 文件上传

### 单文件上传

```python
from fastapi import FastAPI, File, UploadFile

app = FastAPI()


@app.post("/upload/")
async def upload_file(file: UploadFile = File(...)):
    return {
        "filename": file.filename,
        "content_type": file.content_type,
        "size": len(await file.read()),
    }
```

### UploadFile 属性

| 属性 | 说明 |
|------|------|
| `filename` | 上传文件名 |
| `content_type` | MIME 类型 |
| `file` | 文件对象（SpooledTemporaryFile） |

### UploadFile 方法

```python
@app.post("/upload/")
async def upload_file(file: UploadFile = File(...)):
    # 读取内容
    content = await file.read()

    # 移动文件指针到开头
    await file.seek(0)

    # 按行读取
    lines = []
    async for line in file:
        lines.append(line)

    return {"filename": file.filename, "lines": len(lines)}
```

### 保存上传文件

```python
import shutil
from pathlib import Path

UPLOAD_DIR = Path("uploads")
UPLOAD_DIR.mkdir(exist_ok=True)


@app.post("/upload/")
async def upload_file(file: UploadFile = File(...)):
    file_path = UPLOAD_DIR / file.filename

    with file_path.open("wb") as buffer:
        shutil.copyfileobj(file.file, buffer)

    return {
        "filename": file.filename,
        "saved_to": str(file_path),
        "size": file_path.stat().st_size,
    }
```

## 4. 文件验证

### 限制文件类型

```python
from fastapi import HTTPException

ALLOWED_TYPES = {"image/jpeg", "image/png", "image/gif"}
MAX_SIZE = 5 * 1024 * 1024  # 5MB


@app.post("/upload-image/")
async def upload_image(file: UploadFile = File(...)):
    # 检查类型
    if file.content_type not in ALLOWED_TYPES:
        raise HTTPException(
            status_code=400,
            detail=f"只允许上传图片: {ALLOWED_TYPES}",
        )

    # 检查大小
    content = await file.read()
    if len(content) > MAX_SIZE:
        raise HTTPException(
            status_code=400,
            detail=f"文件超过 {MAX_SIZE / 1024 / 1024}MB 限制",
        )

    # 保存...
    return {"filename": file.filename, "size": len(content)}
```

### 自定义文件验证依赖

```python
def validate_image(file: UploadFile = File(...)):
    allowed = {"image/jpeg", "image/png"}
    if file.content_type not in allowed:
        raise HTTPException(400, detail="只支持 jpg/png")
    return file


@app.post("/upload/")
async def upload(file: UploadFile = Depends(validate_image)):
    content = await file.read()
    return {"filename": file.filename, "size": len(content)}
```

## 实战练习

### 练习：完整的文件上传接口

```python
from fastapi import FastAPI, File, UploadFile, HTTPException, Form
from fastapi.responses import FileResponse
from pathlib import Path
import shutil
import uuid

app = FastAPI()

UPLOAD_DIR = Path("uploads")
UPLOAD_DIR.mkdir(exist_ok=True)


def get_unique_filename(original: str) -> str:
    ext = Path(original).suffix
    return f"{uuid.uuid4().hex}{ext}"


@app.post("/upload/")
async def upload_file(
    file: UploadFile = File(...),
    folder: str | None = Form("default"),
):
    # 验证
    if not file.content_type:
        raise HTTPException(400, "无法识别文件类型")

    # 创建子目录
    save_dir = UPLOAD_DIR / folder
    save_dir.mkdir(exist_ok=True)

    # 生成唯一文件名
    unique_name = get_unique_filename(file.filename)
    file_path = save_dir / unique_name

    # 保存
    with file_path.open("wb") as buffer:
        shutil.copyfileobj(file.file, buffer)

    return {
        "original_name": file.filename,
        "saved_name": unique_name,
        "path": f"/{folder}/{unique_name}",
        "size": file_path.stat().st_size,
    }


@app.get("/files/{folder}/{filename}")
def download_file(folder: str, filename: str):
    file_path = UPLOAD_DIR / folder / filename
    if not file_path.exists():
        raise HTTPException(404, "文件不存在")
    return FileResponse(file_path)
```

## 今日总结

- [ ] `Form(...)` 接收 `application/x-www-form-urlencoded` 数据
- [ ] `UploadFile` 提供文件元数据和异步读取方法

- [ ] 上传文件要验证类型和大小
- [ ] 使用唯一文件名避免覆盖和文件名注入
- [ ] 表单和文件可以同时使用

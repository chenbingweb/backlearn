## 1. 路径参数 Path Parameters

### 基础路径参数

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/users/{user_id}")
def get_user(user_id: int):
    return {"user_id": user_id, "type": type(user_id).__name__}
```

访问 `/users/123` → `{"user_id": 123, "type": "int"}`
访问 `/users/abc` → 422 验证错误

### 路径参数类型支持

```python
@app.get("/items/{item_id}")
def get_item_int(item_id: int):          # 整数
    ...

@app.get("/prices/{price}")
def get_price(price: float):             # 浮点数
    ...

@app.get("/flags/{flag}")
def get_flag(flag: bool):                # 布尔值
    ...

@app.get("/uuids/{item_uuid}")
def get_uuid(item_uuid: UUID):           # UUID
    ...

from datetime import date, datetime

@app.get("/dates/{dt}")
def get_date(dt: date):                  # 日期
    ...
```

### 路径顺序很重要

```python
# ❌ 错误：/users/me 永远不会匹配
@app.get("/users/{user_id}")
def get_user(user_id: int): ...

@app.get("/users/me")
def get_current_user(): ...

# ✅ 正确：固定路径放在前面
@app.get("/users/me")
def get_current_user(): ...

@app.get("/users/{user_id}")
def get_user(user_id: int): ...
```

### 路径参数验证（Path）

```python
from fastapi import Path


@app.get("/items/{item_id}")
def get_item(
    item_id: int = Path(
        ...,                    # 必需参数
        title="Item ID",         # 文档标题
        description="唯一标识",
        ge=1,                    # >= 1
        le=1000,                 # <= 1000
    )
):
    return {"item_id": item_id}
```

验证约束：
- `gt` — 大于（>）
- `ge` — 大于等于（>=）
- `lt` — 小于（<）
- `le` — 小于等于（<=）
- `min_length` / `max_length` — 字符串长度
- `regex` — 正则匹配

### 路径参数正则匹配

```python
@app.get("/files/{file_path:path}")  # 匹配包含 / 的路径
def read_file(file_path: str):
    return {"file_path": file_path}

# /files/home/user/docs → file_path="home/user/docs"
```

## 2. 查询参数 Query Parameters

### 基础查询参数

```python
@app.get("/items/")
def list_items(skip: int = 0, limit: int = 10):
    return {"skip": skip, "limit": limit}
```

访问 `/items/?skip=20&limit=5`

### 可选查询参数

```python
@app.get("/items/")
def list_items(
    skip: int = 0,
    limit: int = 10,
    q: str | None = None,   # 可选参数，默认 None
):
    result = {"skip": skip, "limit": limit}
    if q:
        result["q"] = q
    return result
```

### 布尔查询参数

```python
@app.get("/items/")
def list_items(
    skip: int = 0,
    limit: int = 10,
    active: bool = False,   # /items/?active=true
):
    return {"active": active}
```

支持格式：`true`, `True`, `1`, `yes`, `on`

### 查询参数验证（Query）

```python
from fastapi import Query


@app.get("/search/")
def search(
    q: str = Query(
        ...,                    # 必需
        min_length=2,            # 最少2个字符
        max_length=50,           # 最多50个字符
        title="搜索关键词",
        description="支持模糊搜索",
    ),
    sort: str = Query("created", enum=["created", "price", "name"]),
    page: int = Query(1, ge=1),
    page_size: int = Query(20, ge=1, le=100),
):
    return {
        "q": q,
        "sort": sort,
        "page": page,
        "page_size": page_size,
    }
```

### 多值查询参数

```python
@app.get("/items/")
def filter_items(
    tags: list[str] = Query(default=[]),     # ?tags=python&tags=fastapi
    statuses: list[str] | None = Query(None), # ?statuses=pending&statuses=done
):
    return {"tags": tags, "statuses": statuses}
```

### 参数别名

```python
@app.get("/items/")
def list_items(
    item_query: str = Query(
        default=None,
        alias="item-query",      # URL 中使用 item-query
    )
):
    return {"query": item_query}

# 访问 /items/?item-query=hello
```

### 废弃参数

```python
@app.get("/items/")
def list_items(
    q: str | None = Query(
        None,
        deprecated=True,         # 标记为废弃
        description="已废弃，请使用 search 参数",
    ),
    search: str | None = None,
):
    ...
```

### 隐藏参数

```python
@app.get("/items/")
def list_items(
    hidden_param: str = Query(None, include_in_schema=False)
):
    """这个参数不会出现在文档中"""
    ...
```

## 实战练习

### 练习 1：商品搜索接口

```python
from fastapi import FastAPI, Path, Query
from enum import Enum

app = FastAPI()

class SortBy(str, Enum):
    PRICE_ASC = "price_asc"
    PRICE_DESC = "price_desc"
    NEWEST = "newest"
    POPULAR = "popular"


@app.get("/products/{product_id}")
def get_product(
    product_id: int = Path(..., ge=1, description="商品ID")
):
    return {"product_id": product_id}


@app.get("/products/")
def list_products(
    q: str | None = Query(None, min_length=1, max_length=100),
    category: str | None = Query(None),
    min_price: float = Query(0, ge=0),
    max_price: float | None = Query(None, ge=0),
    in_stock: bool = Query(False),
    sort: SortBy = Query(SortBy.NEWEST),
    page: int = Query(1, ge=1),
    page_size: int = Query(20, ge=1, le=100),
):
    return {
        "q": q,
        "category": category,
        "min_price": min_price,
        "max_price": max_price,
        "in_stock": in_stock,
        "sort": sort,
        "page": page,
        "page_size": page_size,
    }
```

### 练习 2：测试各种参数

使用 Swagger UI (`/docs`) 测试以下场景：

## 今日总结

- [ ] 路径参数 `{param}` 自动进行类型转换和验证
- [ ] 路径顺序很重要：固定路径要放在动态路径前面
- [ ] 查询参数默认从 URL `?key=value` 解析
- [ ] `Query()` 提供丰富的验证选项：长度、范围、枚举、别名
- [ ] 可选参数设为 `type | None = None`
- [ ] 多值参数用 `list[str]`
- [ ] 可以用 `deprecated=True` 标记废弃参数

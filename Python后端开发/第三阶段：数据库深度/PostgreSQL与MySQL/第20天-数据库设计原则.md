## 3. 概念设计

### ER 图基础

```
实体(Entity) - 矩形
  ┌─────────┐
  │  User   │
  └─────────┘

属性(Attribute) - 椭圆
    ┌───────┐
    │ name  │
    └───────┘

关系(Relationship) - 菱形
    ◇

主键(Primary Key) - 下划线
    name (带下划线)
```

### 实体关系

```markdown
## 用户-订单关系
一个用户可以有多个订单（1:N）
用户 ──< 订单

## 订单-商品关系（通过订单项）
一个订单包含多个商品，一个商品可被多个订单包含（N:M）
订单 ──< 订单项 >─ 商品

## 商品-分类关系
一个商品属于一个分类，一个分类包含多个商品（1:N）
分类 ──< 商品
```

### 完整性约束

```markdown
## 业务规则
1. 用户必须年满 18 岁
2. 订单金额必须大于 0
3. 商品库存不能为负数
4. 订单状态流转：pending -> paid -> shipped -> completed
5. 取消订单只能在 pending 状态
```

## 4. 逻辑设计

### 表结构设计

```sql
-- 用户表
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) NOT NULL UNIQUE,
    email VARCHAR(100) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    phone VARCHAR(20),
    real_name VARCHAR(50),
    id_card VARCHAR(18),           -- 实名认证
    birthday DATE,
    gender VARCHAR(10),
    avatar_url VARCHAR(255),
    status VARCHAR(20) DEFAULT 'active',  -- active, frozen
    last_login_at TIMESTAMP,
    last_login_ip INET,
    login_count INTEGER DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 地址表
CREATE TABLE addresses (
    id SERIAL PRIMARY KEY,
    user_id INTEGER NOT NULL REFERENCES users(id),
    receiver_name VARCHAR(50) NOT NULL,
    phone VARCHAR(20) NOT NULL,
    province VARCHAR(50) NOT NULL,
    city VARCHAR(50) NOT NULL,
    district VARCHAR(50) NOT NULL,
    detail_address VARCHAR(255) NOT NULL,
    postal_code VARCHAR(10),
    is_default BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 商品表
CREATE TABLE products (
    id SERIAL PRIMARY KEY,
    name VARCHAR(200) NOT NULL,
    category_id INTEGER REFERENCES categories(id),
    brand VARCHAR(50),
    model VARCHAR(50),             -- 型号
    price DECIMAL(10,2) NOT NULL,
    cost DECIMAL(10,2),            -- 成本
    original_price DECIMAL(10,2),  -- 原价
    stock INTEGER DEFAULT 0,
    sold_count INTEGER DEFAULT 0,
    weight DECIMAL(8,2),           -- 重量（克）
    unit VARCHAR(20) DEFAULT '件', -- 单位
    barcode VARCHAR(30),           -- 条形码
    description TEXT,
    is_on_sale BOOLEAN DEFAULT TRUE,
    is_hot BOOLEAN DEFAULT FALSE,
    is_new BOOLEAN DEFAULT FALSE,
    sort_order INTEGER DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 订单表
CREATE TABLE orders (
    id SERIAL PRIMARY KEY,
    order_no VARCHAR(50) NOT NULL UNIQUE,
    user_id INTEGER NOT NULL REFERENCES users(id),
    address_id INTEGER REFERENCES addresses(id),
    total_amount DECIMAL(10,2) NOT NULL,    -- 商品总价
    freight_amount DECIMAL(10,2) DEFAULT 0, -- 运费
    discount_amount DECIMAL(10,2) DEFAULT 0, -- 优惠金额
    payment_amount DECIMAL(10,2) NOT NULL, -- 实付金额
    points_discount DECIMAL(10,2) DEFAULT 0, -- 积分抵扣
    coupon_id INTEGER,
    coupon_discount DECIMAL(10,2) DEFAULT 0,
    status VARCHAR(20) DEFAULT 'pending',
    payment_method VARCHAR(20),
    payment_time TIMESTAMP,
    shipped_time TIMESTAMP,
    completed_time TIMESTAMP,
    cancelled_time TIMESTAMP,
    cancel_reason VARCHAR(255),
    buyer_note VARCHAR(500),       -- 买家备注
    admin_note VARCHAR(500),      -- 管理员备注
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 5. 物理设计

### 存储引擎选择

```sql
-- PostgreSQL（默认推荐）
-- 适合：OLTP、复杂查询、数据完整性要求高

-- MySQL 存储引擎选择
CREATE TABLE orders (
    ...
) ENGINE = InnoDB;  -- 默认，推荐用于大多数场景

CREATE TABLE log (
    ...
) ENGINE = MyISAM;  -- 适合只读日志，高速插入

-- MySQL 8.0+ 默认 InnoDB
```

### 表空间设计

```sql
-- PostgreSQL 表空间
CREATE TABLESPACE fast_disk LOCATION '/data/fast';
CREATE TABLESPACE slow_disk LOCATION '/data/slow';

-- 将大表放在快速存储
CREATE TABLE orders (...) TABLESPACE fast_disk;

-- 将索引放在快速存储
CREATE INDEX idx_orders_created ON orders(created_at) TABLESPACE fast_disk;
```

### 分区策略

```sql
-- PostgreSQL 表分区（按时间）
CREATE TABLE orders (
    id SERIAL,
    order_no VARCHAR(50),
    created_at TIMESTAMP,
    ...
) PARTITION BY RANGE (created_at);

CREATE TABLE orders_2024 PARTITION OF orders
    FOR VALUES FROM ('2024-01-01') TO ('2025-01-01');

CREATE TABLE orders_2025 PARTITION OF orders
    FOR VALUES FROM ('2025-01-01') TO ('2026-01-01');

-- MySQL 表分区
CREATE TABLE orders (
    id INT,
    order_no VARCHAR(50),
    created_at DATE,
    ...
) PARTITION BY RANGE (YEAR(created_at)) (
    PARTITION p2024 VALUES LESS THAN (2025),
    PARTITION p2025 VALUES LESS THAN (2026),
    PARTITION pmax VALUES LESS THAN MAXVALUE
);
```

## 6. 实战练习

### 练习：博客系统设计

```markdown
## 需求分析
- 用户：注册、登录、写博客、评论、点赞
- 博客：分类、标签、正文、附件
- 评论：嵌套评论、审核

## 识别实体
- 用户 (User)
- 博客文章 (Post)
- 分类 (Category)
- 标签 (Tag)
- 评论 (Comment)
- 点赞 (Like)
- 附件 (Attachment)

## 关系
- 用户 1:N 博客
- 用户 1:N 评论
- 博客 1:N 评论
- 博客 N:M 标签
- 用户 1:N 点赞
- 博客 1:N 点赞
```

```sql
-- 实现博客系统表结构
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) NOT NULL UNIQUE,
    email VARCHAR(100) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    nickname VARCHAR(50),
    avatar_url VARCHAR(255),
    bio VARCHAR(500),
    is_verified BOOLEAN DEFAULT FALSE,
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE categories (
    id SERIAL PRIMARY KEY,
    name VARCHAR(50) NOT NULL,
    slug VARCHAR(50) NOT NULL UNIQUE,
    parent_id INTEGER REFERENCES categories(id),
    description VARCHAR(255),
    sort_order INTEGER DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE posts (
    id SERIAL PRIMARY KEY,
    user_id INTEGER NOT NULL REFERENCES users(id),
    category_id INTEGER REFERENCES categories(id),
    title VARCHAR(200) NOT NULL,
    slug VARCHAR(200) NOT NULL UNIQUE,
    summary TEXT,
    content TEXT,
    cover_image VARCHAR(255),
    view_count INTEGER DEFAULT 0,
    comment_count INTEGER DEFAULT 0,
    like_count INTEGER DEFAULT 0,
    is_published BOOLEAN DEFAULT FALSE,
    is_featured BOOLEAN DEFAULT FALSE,
    published_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE tags (
    id SERIAL PRIMARY KEY,
    name VARCHAR(50) NOT NULL UNIQUE,
    slug VARCHAR(50) NOT NULL UNIQUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE post_tags (
    post_id INTEGER REFERENCES posts(id) ON DELETE CASCADE,
    tag_id INTEGER REFERENCES tags(id) ON DELETE CASCADE,
    PRIMARY KEY (post_id, tag_id)
);

CREATE TABLE comments (
    id SERIAL PRIMARY KEY,
    post_id INTEGER NOT NULL REFERENCES posts(id) ON DELETE CASCADE,
    user_id INTEGER REFERENCES users(id),
    parent_id INTEGER REFERENCES comments(id),
    content TEXT NOT NULL,
    like_count INTEGER DEFAULT 0,
    is_approved BOOLEAN DEFAULT TRUE,
    ip_address INET,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE likes (
    id SERIAL PRIMARY KEY,
    user_id INTEGER NOT NULL REFERENCES users(id),
    post_id INTEGER REFERENCES posts(id) ON DELETE CASCADE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(user_id, post_id)
);
```

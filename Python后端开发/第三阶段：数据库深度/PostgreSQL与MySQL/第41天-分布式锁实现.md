## 1. 分布式锁基础

### 为什么需要分布式锁

```markdown
单进程多线程：
  线程A ──► 获取锁 ──► 操作 ──► 释放锁
  线程B ──►   等待   ──► 获取锁 ──► 操作

多进程（多台服务器）：
  进程A(服务器1) ──► ??? ──► 如何保证互斥 ???

  进程B(服务器2) ──► ??? ──► 需要分布式锁
```

### 分布式锁要求

```
1. 互斥：任意时刻只有一个客户端能持有锁
2. 无死锁：持有锁的客户端崩溃后，锁能被释放
3. 容错：大部分 Redis 节点正常就能获取/释放锁
4. 公平：按请求顺序获取锁
```

### Redis 分布式锁原理

```
客户端A                      Redis                       客户端B
   │                           │                           │
   │ SET lock order:1001 1 NX │                           │
   │ ─────────────────────────►│                           │
   │◄─────────────── OK ──────│                           │
   │     (获取锁成功)          │                           │
   │                           │                           │
   │ [执行业务操作]            │                           │
   │                           │ SET lock order:1001 1 NX │
   │                           │ ◄─────────────────────────│
   │                           │◄─────────── NIL ─────────│
   │                           │     (获取锁失败)          │
   │                           │     (返回nil/false)       │
   │                           │                           │
   │ DEL lock                  │                           │
   │ ─────────────────────────►│                           │
   │◄─────────── OK ──────────│                           │
```

## 2. 基础分布式锁

### 简单实现

```python
import redis
import time
import uuid

class SimpleLock:
    """简单分布式锁"""

    def __init__(self, redis_client, lock_name, timeout=10):
        self.r = redis_client
        self.lock_name = f'lock:{lock_name}'
        self.timeout = timeout
        self.token = str(uuid.uuid4())  # 唯一标识

    def acquire(self):
        """获取锁"""
        # NX：不存在才设置
        # EX：过期时间（秒）
        result = self.r.set(
            self.lock_name,
            self.token,
            nx=True,
            ex=self.timeout
        )
        return result is not None

    def release(self):
        """释放锁"""
        # Lua 脚本保证原子性
        script = """
        if redis.call("get", KEYS[1]) == ARGV[1] then
            return redis.call("del", KEYS[1])
        else
            return 0
        end
        """
        result = self.r.eval(script, 1, self.lock_name, self.token)
        return result == 1

    def __enter__(self):
        if not self.acquire():
            raise TimeoutError(f"Failed to acquire lock: {self.lock_name}")
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        self.release()
```

### 使用示例

```python
r = redis.Redis()

# 方式1：上下文管理器
with SimpleLock(r, 'order:1001') as lock:
    # 获取锁成功，执行操作
    order = get_order(1001)
    order.status = 'paid'
    save_order(order)
# 自动释放锁

# 方式2：手动管理
lock = SimpleLock(r, 'inventory:sku:123')
if lock.acquire():
    try:
        inventory = get_inventory('sku:123')
        inventory.stock -= 1
        save_inventory(inventory)
    finally:
        lock.release()
else:
    print('获取锁失败')
```

### 问题分析

```markdown
简单实现的缺陷：

1. 锁过期，但业务还在执行
   线程A 获取锁（10秒过期）
     │
     ▼
   执行业务（需要15秒）
     │
     ▼
   锁自动释放（10秒后）
     │
     ▼
   线程B 获取锁（同一资源）
     │
     ▼
   线程A 和 线程B 同时操作（数据不一致）

2. Redis 主从切换问题
   主库加锁成功
     │
     ▼
   主库崩溃，切换到从库
     │
     ▼
   从库没有锁数据（新主库）
     │
     ▼
   另一个客户端获取锁成功
     │
     ▼
   两个客户端同时持有锁
```

## 3. 改进：看门狗机制

### 原理

```
锁持有者                      后台任务
   │                           │
   │ 获取锁                      │
   │ ◄────────────────────────── │
   │                           │
   │ 启动看门狗                  │
   │ ◄────────────────────────── │
   │                           │
   │ [业务执行中]                │
   │                           │ 每隔 timeout/3 秒
   │                           │ 检查并续期
   │◄──────────────────────────│
   │                           │
   │ 业务完成，释放锁            │
   │ ◄────────────────────────── │
   │                           │
   │ 看门狗停止                  │
   │ ◄────────────────────────── │
```

### 实现

```python
import redis
import uuid
import threading
import time

class WatchdogLock:
    """带看门狗的分布式锁"""

    def __init__(self, redis_client, lock_name, timeout=30):
        self.r = redis_client
        self.lock_name = f'lock:{lock_name}'
        self.timeout = timeout
        self.token = str(uuid.uuid4())
        self._watchdog_thread = None
        self._stop_event = threading.Event()

    def acquire(self):
        """获取锁"""
        result = self.r.set(
            self.lock_name,
            self.token,
            nx=True,
            ex=self.timeout
        )

        if result:
            # 启动看门狗
            self._start_watchdog()

        return result is not None

    def _start_watchdog(self):
        """启动看门狗"""
        self._stop_event.clear()
        self._watchdog_thread = threading.Thread(
            target=self._watchdog_task,
            daemon=True
        )
        self._watchdog_thread.start()

    def _watchdog_task(self):
        """看门狗任务：自动续期"""
        while not self._stop_event.is_set():
            # 每 timeout/3 秒续期一次
            time.sleep(self.timeout / 3)

            if self._stop_event.is_set():
                break

            # 检查锁是否还是自己的
            current_token = self.r.get(self.lock_name)
            if current_token == self.token:
                # 续期
                self.r.expire(self.lock_name, self.timeout)

    def release(self):
        """释放锁"""
        # 停止看门狗
        self._stop_event.set()
        if self._watchdog_thread:
            self._watchdog_thread.join(timeout=1)

        # 释放锁（Lua 脚本）
        script = """
        if redis.call("get", KEYS[1]) == ARGV[1] then
            return redis.call("del", KEYS[1])
        else
            return 0
        end
        """
        self.r.eval(script, 1, self.lock_name, self.token)

    def extend(self, additional_time=None):
        """延长锁持有时间"""
        if additional_time is None:
            additional_time = self.timeout

        script = """
        if redis.call("get", KEYS[1]) == ARGV[1] then
            return redis.call("expire", KEYS[1], ARGV[2])
        else
            return 0
        end
        """
        return self.r.eval(
            script, 1,
            self.lock_name, self.token,
            additional_time
        ) == 1

    def __enter__(self):
        if not self.acquire():
            raise TimeoutError(f"Failed to acquire lock: {self.lock_name}")
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        self.release()
```

## 4. Redlock 算法

### 原理

```
Redis 分布式锁的正确实现：Redlock

方案：使用多个独立的 Redis 实例
      （不要和 Redis Cluster 混淆）

┌─────────┐  ┌─────────┐  ┌─────────┐
│ Redis 1 │  │ Redis 2 │  │ Redis 3 │
│ (主)    │  │ (主)    │  │ (主)    │
└─────────┘  └─────────┘  └─────────┘
     │            │            │
     │            │            │
     ▼            ▼            ▼
获取锁尝试N/2+1个成功 ──► 成功获取锁
```

### Redlock 实现

```python
import redis
import uuid
import time

class RedLock:
    """Redlock 分布式锁"""

    # 重试配置
    DEFAULT_RETRY_COUNT = 3
    DEFAULT_RETRY_DELAY = 0.2  # 秒
    CLOCK_DRIFT_FACTOR = 0.01  # 时钟漂移因子

    def __init__(self, redis_servers):
        """
        redis_servers: list of Redis connections
        示例：[r1, r2, r3]
        """
        self.redis_servers = redis_servers
        self.quorum = len(redis_servers) // 2 + 1
        self.timeout = 10  # 锁持有时间（秒）

    def _get_unique_id(self):
        """生成唯一 ID"""
        return str(uuid.uuid4())

    def acquire(self, resource_name):
        """获取锁"""
        lock_name = f'redlock:{resource_name}'
        token = self._get_unique_id()
        retry_count = self.DEFAULT_RETRY_COUNT

        while retry_count > 0:
            acquired_count = 0
            start_time = time.time()

            # 向所有 Redis 实例尝试获取锁
            for r in self.redis_servers:
                if self._try_acquire(r, lock_name, token):
                    acquired_count += 1

            # 计算漂移时间
            elapsed = time.time() - start_time
            drift = self.CLOCK_DRIFT_FACTOR * self.timeout + elapsed
            validity_time = self.timeout - drift

            # 检查是否获取了足够的锁
            if acquired_count >= self.quorum and validity_time > 0:
                self.token = token
                self.resource_name = resource_name
                self.lock_name = lock_name
                return True

            # 获取锁失败，释放已获取的锁
            for r in self.redis_servers:
                self._release(r, lock_name, token)

            # 重试前等待
            time.sleep(self.DEFAULT_RETRY_DELAY)
            retry_count -= 1

        return False

    def _try_acquire(self, r, lock_name, token):
        """尝试在单个 Redis 实例获取锁"""
        result = r.set(
            lock_name,
            token,
            nx=True,
            ex=self.timeout
        )
        return result is not None

    def release(self):
        """释放锁"""
        if not hasattr(self, 'token'):
            return False

        lock_name = f'redlock:{self.resource_name}'

        # 向所有实例发送释放命令
        for r in self.redis_servers:
            self._release(r, lock_name, self.token)

        return True

    def _release(self, r, lock_name, token):
        """释放单个实例的锁"""
        script = """
        if redis.call("get", KEYS[1]) == ARGV[1] then
            return redis.call("del", KEYS[1])
        else
            return 0
        end
        """
        r.eval(script, 1, lock_name, token)

    def extend(self, additional_time=None):
        """延长锁持有时间"""
        if not hasattr(self, 'token'):
            return False

        if additional_time is None:
            additional_time = self.timeout

        lock_name = f'redlock:{self.resource_name}'

        # 需要多数实例同意才能续期
        extended_count = 0
        for r in self.redis_servers:
            script = """
            if redis.call("get", KEYS[1]) == ARGV[1] then
                return redis.call("expire", KEYS[1], ARGV[2])
            else
                return 0
            end
            """
            if r.eval(script, 1, lock_name, self.token, additional_time):
                extended_count += 1

        return extended_count >= self.quorum


# 使用示例
r1 = redis.Redis(host='redis1.example.com', port=6379)
r2 = redis.Redis(host='redis2.example.com', port=6379)
r3 = redis.Redis(host='redis3.example.com', port=6379)

lock = RedLock([r1, r2, r3])

if lock.acquire('order:1001'):
    try:
        # 业务操作
        process_order(1001)
    finally:
        lock.release()
```

## 5. 分布式锁应用场景

### 场景1：库存扣减

```python
class InventoryService:
    """库存服务"""

    def __init__(self, redis_client):
        self.r = redis_client

    def deduct_stock(self, sku_id, quantity):
        """扣减库存"""
        lock = WatchdogLock(self.r, f'inventory:{sku_id}', timeout=30)

        with lock:
            # 获取当前库存
            stock_key = f'inventory:{sku_id}:stock'
            current = int(self.r.get(stock_key) or 0)

            if current < quantity:
                raise Exception(f'库存不足：{current} < {quantity}')

            # 扣减库存
            new_stock = current - quantity
            self.r.set(stock_key, new_stock)

            return new_stock
```

### 场景2：订单幂等

```python
class IdempotentService:
    """幂等服务"""

    def __init__(self, redis_client):
        self.r = redis_client

    def execute_with_idempotent(self, order_id, process_func):
        """幂等执行"""
        idempotent_key = f'idempotent:order:{order_id}'

        # 检查是否已处理
        exists = self.r.exists(idempotent_key)
        if exists:
            return {'status': 'already_processed', 'order_id': order_id}

        # 设置幂等标记（防止重复执行）
        self.r.setex(idempotent_key, 86400, 'processing')

        try:
            # 执行业务
            result = process_func(order_id)

            # 标记完成
            self.r.setex(idempotent_key, 86400, 'completed')

            return result
        except Exception as e:
            # 失败时删除标记，允许重试
            self.r.delete(idempotent_key)
            raise e
```

### 场景3：定时任务分布式协调

```python
class DistributedScheduler:
    """分布式定时任务调度"""

    def __init__(self, redis_client):
        self.r = redis_client

    def acquire_job_lock(self, job_name, worker_id, timeout=60):
        """获取任务锁"""
        lock_key = f'scheduler:lock:{job_name}'
        holder_key = f'scheduler:holder:{job_name}'

        # 使用 SET NX
        acquired = self.r.set(
            lock_key,
            worker_id,
            nx=True,
            ex=timeout
        )

        if acquired:
            # 记录持有者
            self.r.set(holder_key, worker_id, ex=timeout)
            return True

        return False

    def release_job_lock(self, job_name, worker_id):
        """释放任务锁"""
        lock_key = f'scheduler:lock:{job_name}'
        holder_key = f'scheduler:holder:{job_name}'

        # 只允许持有者释放
        current_holder = self.r.get(holder_key)
        if current_holder == worker_id:
            self.r.delete(lock_key)
            self.r.delete(holder_key)
            return True

        return False

    def run_job(self, job_name, job_func, worker_id):
        """运行定时任务"""
        if self.acquire_job_lock(job_name, worker_id):
            try:
                print(f'Worker {worker_id} executing job {job_name}')
                return job_func()
            finally:
                self.release_job_lock(job_name, worker_id)
        else:
            print(f'Worker {worker_id} could not acquire lock for {job_name}')
            return None
```

## 6. 注意事项

### 不要在锁内执行长时间操作

```python
# ❌ 错误：长时间操作导致锁过期
with lock:
    call_external_api()  # 可能很慢
    process_large_data()  # 可能很慢

# ✅ 正确：拆分锁粒度
with lock:
    prepare_data()

without lock:
    call_external_api()  # 锁外执行耗时操作

with lock:
    save_result()
```

### 合理设置超时时间

```python
# ❌ 错误：超时时间过短
lock = WatchdogLock(r, 'task', timeout=1)  # 1秒太短

# ✅ 正确：超时时间应大于正常操作时间
lock = WatchdogLock(r, 'task', timeout=30)
```

### 幂等性设计

```python
# ✅ 所有获取锁的操作都应该是幂等的
# 释放锁时检查 token
script = """
if redis.call("get", KEYS[1]) == ARGV[1] then
    return redis.call("del", KEYS[1])
else
    return 0
end
"""
```

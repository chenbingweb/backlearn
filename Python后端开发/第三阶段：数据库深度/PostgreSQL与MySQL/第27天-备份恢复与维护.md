## 1. 备份策略

### 备份类型

```
┌─────────────────────────────────────────────────────┐
│                   备份类型                           │
├─────────────────────────────────────────────────────┤
│                                                     │
│  全量备份（Full Backup）                             │
│  - 备份整个数据库                                    │
│  - 恢复快，但占用空间大                              │
│  - 频率：每周一次                                    │
│                                                     │
│  增量备份（Incremental Backup）                      │
│  - 只备份自上次备份以来的变化                        │
│  - 占用空间小，但恢复复杂                            │
│  - 频率：每天                                        │
│                                                     │
│  差异备份（Differential Backup）                     │
│  - 备份自上次全量备份以来的变化                      │
│  - 介于全量和增量之间                                │
│  - 频率：每天                                        │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 备份时机

```markdown
## 备份计划示例
1. 每日凌晨 2:00：增量备份
2. 每周日凌晨 3:00：全量备份

4. 保留策略：最近 7 天每日 + 最近 4 周每周 + 最近 6 月每月
```

## 2. PostgreSQL 备份

### pg_dump 全量备份

```bash
# 备份单个数据库
pg_dump -h localhost -U postgres -d mydb -F c -f backup.dump
# -F c: 自定义格式（压缩）
# -F p: 明文 SQL
# -F t: tar 格式

# 备份所有数据库
pg_dumpall -h localhost -U postgres -f all_databases.sql

# 压缩备份
pg_dump -h localhost -U postgres -d mydb | gzip > backup.dump.gz

# 备份指定表
pg_dump -h localhost -U postgres -d mydb -t products -t orders > tables.sql
```

### 恢复

```bash
# 恢复 SQL 格式备份
psql -h localhost -U postgres -d mydb -f backup.sql

# 恢复压缩备份
pg_restore -h localhost -U postgres -d mydb -c backup.dump
# -c: 先删除已存在的对象

# 创建新数据库并恢复
createdb -h localhost -U postgres newdb
pg_restore -h localhost -U postgres -d newdb backup.dump
```

### 物理备份（文件系统）

```bash
# PostgreSQL 物理备份需要停止数据库
pg_ctl stop

# 复制数据目录
rsync -av /var/lib/postgresql/data /backup/postgres/

# 或使用 tar
tar -cvzf backup.tar.gz /var/lib/postgresql/data

# 恢复
pg_ctl stop
rm -rf /var/lib/postgresql/data
tar -xvzf backup.tar.gz -C /
pg_ctl start
```

### WAL 归档（连续备份）

```sql
-- 配置 postgresql.conf
wal_level = replica
max_wal_senders = 3
wal_keep_size = 1GB

-- 开启归档
archive_mode = on
archive_command = 'cp %p /archive/%f'

-- 或使用流复制
archive_command = 'rsync -a %p backupserver:/archive/%f'
```

## 3. MySQL 备份

### mysqldump 全量备份

```bash
# 备份单个数据库
mysqldump -h localhost -u root -p mydb > backup.sql

# 备份所有数据库
mysqldump -h localhost -u root -p --all-databases > all_databases.sql

# 备份指定表
mysqldump -h localhost -u root -p mydb products orders > tables.sql

# 选项说明
# --single-transaction: 事务级别备份（InnoDB）
# --master-data: 记录复制信息
# --triggers: 包含触发器
# --routines: 包含存储过程
# --events: 包含事件

# 生产环境推荐
mysqldump \
    -h localhost \
    -u root \
    -p \
    --single-transaction \
    --master-data=2 \
    --triggers \
    --routines \
    --events \
    mydb > backup.sql
```

### 恢复

```bash
# 恢复 SQL 备份
mysql -h localhost -u root -p mydb < backup.sql

# 恢复压缩备份
gunzip < backup.sql.gz | mysql -h localhost -u root -p

# 恢复指定表
mysqlimport -h localhost -u root -p mydb --replace backup.sql
```

### xtrabackup（热备份）

```bash
# 安装
# yum install percona-xtrabackup

xtrabackup --backup --target-dir=/backup/full --user=root --password=xxx
```

## 4. Python 备份脚本

### PostgreSQL 备份脚本

```python
import subprocess
import os
from datetime import datetime
import gzip
import shutil

class PostgreSQLBackup:
    def __init__(self, db_config):
        self.db_config = db_config
        self.backup_dir = '/backup/postgres'
        os.makedirs(self.backup_dir, exist_ok=True)

    def backup(self, db_name, compression=True):
        timestamp = datetime.now().strftime('%Y%m%d_%H%M%S')
        filename = f'{db_name}_{timestamp}'

        if compression:
            backup_file = f'{self.backup_dir}/{filename}.dump.gz'
            with open(backup_file, 'wb') as f:
                process = subprocess.Popen(
                    [
                        'pg_dump', '-h', self.db_config['host'],
                        '-U', self.db_config['user'],
                        '-d', db_name,
                        '-F', 'c'
                    ],
                    stdout=subprocess.PIPE
                )
                gzip_file = gzip.open(backup_file, 'wb')
                shutil.copyfileobj(process.stdout, gzip_file)
                gzip_file.close()
                process.wait()
        else:
            backup_file = f'{self.backup_dir}/{filename}.sql'
            with open(backup_file, 'w') as f:
                subprocess.run(
                    [
                        'pg_dump', '-h', self.db_config['host'],
                        '-U', self.db_config['user'],
                        '-d', db_name,
                        '-F', 'p'
                    ],
                    stdout=f
                )

        print(f"Backup created: {backup_file}")
        return backup_file

    def restore(self, backup_file, db_name):
        """恢复备份"""
        if backup_file.endswith('.gz'):
            process = subprocess.Popen(
                ['gunzip', '-c', backup_file],
                stdout=subprocess.PIPE
            )
            restore_process = subprocess.Popen(
                [
                    'pg_restore', '-h', self.db_config['host'],
                    '-U', self.db_config['user'],
                    '-d', db_name,
                    '-c'
                ],
                stdin=process.stdout
            )
            process.stdout.close()
            restore_process.wait()
        else:
            with open(backup_file, 'r') as f:
                subprocess.run(
                    [
                        'psql', '-h', self.db_config['host'],
                        '-U', self.db_config['user'],
                        '-d', db_name
                    ],
                    stdin=f
                )

        print(f"Backup restored from: {backup_file}")

    def cleanup_old_backups(self, keep_days=7):
        """清理旧备份"""
        import time
        cutoff = time.time() - (keep_days * 86400)

        for filename in os.listdir(self.backup_dir):
            filepath = os.path.join(self.backup_dir, filename)
            if os.path.getmtime(filepath) < cutoff:
                os.remove(filepath)
                print(f"Deleted old backup: {filepath}")
```

### MySQL 备份脚本

```python
import subprocess
import os
from datetime import datetime
import shutil
import gzip

class MySQLBackup:
    def __init__(self, db_config):
        self.db_config = db_config
        self.backup_dir = '/backup/mysql'
        os.makedirs(self.backup_dir, exist_ok=True)

    def backup(self, db_name, compression=True):
        timestamp = datetime.now().strftime('%Y%m%d_%H%M%S')
        backup_file = f'{self.backup_dir}/{db_name}_{timestamp}.sql'

        cmd = [
            'mysqldump',
            '-h', self.db_config['host'],
            '-u', self.db_config['user'],
            f'-p{self.db_config["password"]}',
            '--single-transaction',
            '--master-data=2',
            db_name
        ]

        if compression:
            with gzip.open(f'{backup_file}.gz', 'wb') as f:
                subprocess.run(cmd, stdout=f)
            os.remove(backup_file)
            backup_file = f'{backup_file}.gz'
        else:
            with open(backup_file, 'w') as f:
                subprocess.run(cmd, stdout=f)

        print(f"Backup created: {backup_file}")
        return backup_file

    def restore(self, backup_file, db_name):
        """恢复备份"""
        if backup_file.endswith('.gz'):
            cmd = ['mysql', '-h', self.db_config['host'],
                   '-u', self.db_config['user']]
        else:
            cmd = ['mysql', '-h', self.db_config['host'],
                   '-u', self.db_config['user'],
                   db_name]

        subprocess.run(cmd, stdin=open(backup_file, 'rb' if backup_file.endswith('.gz') else 'r'))
        print(f"Restored from: {backup_file}")
```

## 5. 日常维护

### PostgreSQL 维护

```sql
--  vacuum：清理死元组
VACUUM;                    -- 普通 vacuum
VACUUM FULL;              -- 全量 vacuum（需排他锁）
VACUUM ANALYZE;           -- vacuum 并分析

-- 重建索引
REINDEX INDEX idx_orders_status;
REINDEX TABLE orders;

-- 检查表膨胀
SELECT
    relname,
    n_dead_tup,
    n_live_tup,
    ROUND(n_dead_tup::numeric / NULLIF(n_live_tup + n_dead_tup, 0) * 100, 2) AS dead_pct
FROM pg_stat_user_tables
ORDER BY n_dead_tup DESC;

-- 检查索引使用
SELECT
    indexrelname,
    idx_scan,
    idx_tup_read,
    idx_tup_fetch
FROM pg_stat_user_indexes
ORDER BY idx_scan ASC;
```

## 6. 监控指标

### PostgreSQL 监控

```sql
-- 连接数
SELECT
    datname,
    numbackends,
    xact_commit,
    xact_rollback,
    blks_read,
    blks_hit,
    ROUND(100 * blks_hit / NULLIF(blks_read + blks_hit, 0), 2) AS cache_hit_ratio
FROM pg_stat_database
WHERE datname = 'mydb';

-- 慢查询
SELECT
    query,
    calls,
    total_time,
    ROUND(mean_time, 2) AS mean_ms,
    rows
FROM pg_stat_statements
ORDER BY total_time DESC
LIMIT 10;

-- 长时间运行的事务
SELECT
    pid,
    usename,
    state,
    query_start,
    now() - query_start AS duration,
    query
FROM pg_stat_activity
WHERE state != 'idle'
AND query_start < NOW() - INTERVAL '5 minutes'
ORDER BY query_start;
```

### MySQL 监控

```sql
-- 连接状态
SHOW STATUS LIKE 'Threads_connected';
```

## 7. 高可用方案

### PostgreSQL 高可用

```markdown
┌─────────────┐       复制       ┌─────────────┐
│   Primary   │ ───────────────> │   Standby   │
│  (读写)      │                  │  (只读)      │
└─────────────┘                  └─────────────┘

## 故障切换
┌─────────────┐
│  主库宕机    │
└──────┬──────┘
       ▼
┌─────────────┐
│  自动切换    │
│  Standby -> │
│  Primary    │
└─────────────┘
```

### 流复制配置

```bash
# 主库 postgresql.conf
wal_level = replica
max_wal_senders = 3
wal_keep_size = 1GB

# 主库 pg_hba.conf
host replication all 127.0.0.1/32 scram-sha-256

# 创建复制用户
CREATE USER replicator WITH REPLICATION PASSWORD 'password';

# 从库配置（恢复配置）
# standby.signal
standby_mode = 'on'
primary_conninfo = 'host=127.0.0.1 port=5432 user=replicator'
```

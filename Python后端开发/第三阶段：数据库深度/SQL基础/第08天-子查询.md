## 1. 子查询基础

### 什么是子查询

子查询是嵌套在另一个查询中的查询，可以出现在 SELECT、FROM、WHERE、HAVING 等子句中。

```sql
-- 找出价格高于平均价的商品
SELECT * FROM products
WHERE price > (SELECT AVG(price) FROM products);
--                                      ^
--                              子查询
```

### 子查询分类

| 类型 | 位置 | 返回值 |
|------|------|--------|
| 标量子查询 | SELECT、WHERE | 单个值 |
| 列子查询 | WHERE IN | 一列值 |
| 行子查询 | WHERE | 一行值 |
| 表子查询 | FROM | 多行多列 |

## 2. 标量子查询

### 基本用法

```sql
-- 单个值子查询
SELECT
    name,
    price,
    (SELECT AVG(price) FROM products) AS avg_price,
    price - (SELECT AVG(price) FROM products) AS diff
FROM products
WHERE price > (SELECT AVG(price) FROM products);
```

### 在 SELECT 中使用

```sql
SELECT
    o.order_no,
    o.total,
    u.username,
    (SELECT COUNT(*) FROM orders WHERE user_id = u.id) AS user_order_count
FROM orders o
JOIN users u ON o.user_id = u.id;
```

### 在 WHERE 中使用

```sql
-- 找出订单金额大于用户平均订单金额的订单
SELECT * FROM orders
WHERE total > (
    SELECT AVG(total) FROM orders WHERE user_id = orders.user_id
);

-- 找出比最贵商品还贵的产品
SELECT * FROM products
WHERE price > (SELECT MAX(price) FROM products);
```

## 3. 列子查询

### IN 运算符

```sql
-- 找出有订单的用户
SELECT * FROM users
WHERE id IN (
    SELECT DISTINCT user_id FROM orders
);

-- 找出没有订单的用户
SELECT * FROM users
WHERE id NOT IN (
    SELECT DISTINCT user_id FROM orders WHERE user_id IS NOT NULL
);
```

### ANY/SOME/ALL

```sql
-- ANY/SOME：任一满足
SELECT * FROM products
WHERE price > ANY (
    SELECT price FROM products WHERE category = 'electronics'
);

-- ALL：全部满足
SELECT * FROM products
WHERE price > ALL (
    SELECT price FROM products WHERE category = 'books'
);

-- SOME 等价于 ANY
SELECT * FROM products
WHERE price > SOME (
    SELECT price FROM products WHERE category = 'electronics'
);
```

### 使用示例

```sql
-- 找出消费超过所有用户平均值10倍的用户
SELECT * FROM users
WHERE (
    SELECT COALESCE(SUM(total), 0) FROM orders WHERE user_id = users.id
) > 10 * (
    SELECT COALESCE(AVG(total), 0) FROM orders
);
```

## 4. 行子查询

### 返回一行

```sql
-- 找出满足特定条件的用户
SELECT *
FROM users
WHERE (username, email) = (
    SELECT username, email FROM users WHERE id = 1
);
```

### IN 的行子查询

```sql
-- 找出符合多条件的订单
SELECT * FROM orders
WHERE (user_id, status) IN (
    SELECT user_id, 'pending' FROM orders GROUP BY user_id HAVING COUNT(*) > 3
);
```

## 5. 表子查询

### 在 FROM 中使用

```sql
-- 作为临时表
SELECT
    category,
    AVG(price) AS avg_price
FROM (
    SELECT * FROM products WHERE is_active = TRUE
) AS active_products
GROUP BY category;

-- 子查询与 JOIN
SELECT
    u.username,
    stats.order_count,
    stats.total_amount
FROM users u
JOIN (
    SELECT
        user_id,
        COUNT(*) AS order_count,
        SUM(total) AS total_amount
    FROM orders
    GROUP BY user_id
) stats ON u.id = stats.user_id;
```

### 复杂统计

```sql
-- 按月份统计订单，并与上月对比
SELECT
    current.month,
    current.order_count AS orders,
    previous.order_count AS prev_orders,
    current.order_count - COALESCE(previous.order_count, 0) AS growth
FROM (
    SELECT TO_CHAR(created_at, 'YYYY-MM') AS month, COUNT(*) AS order_count
    FROM orders
    GROUP BY TO_CHAR(created_at, 'YYYY-MM')
) current
LEFT JOIN (
    SELECT TO_CHAR(created_at, 'YYYY-MM') AS month, COUNT(*) AS order_count
    FROM orders
    GROUP BY TO_CHAR(created_at, 'YYYY-MM')
) previous ON current.month = previous.month + INTERVAL '1 month';
```

## 6. EXISTS 谓词

### EXISTS 用法

```sql
-- EXISTS：检查子查询是否返回行
-- 找出有订单的用户
SELECT * FROM users u
WHERE EXISTS (
    SELECT 1 FROM orders WHERE user_id = u.id
);

-- NOT EXISTS：找出没有订单的用户
SELECT * FROM users u
WHERE NOT EXISTS (
    SELECT 1 FROM orders WHERE user_id = u.id
);
```

### 与 IN 的区别

```sql
-- IN vs EXISTS（功能相似）
SELECT * FROM users WHERE id IN (SELECT user_id FROM orders);
SELECT * FROM users WHERE EXISTS (SELECT 1 FROM orders WHERE orders.user_id = users.id);

-- 区别：
-- IN 先执行子查询，结果用于 IN 判断
-- EXISTS 先从外查询取行，再检查子查询是否有匹配
-- 一般 EXISTS 效率更高（尤其是子查询表大的情况）
```

### 相关子查询

```sql
-- 相关子查询：子查询引用外查询的列
-- 找出每个用户的最贵订单
SELECT * FROM orders o1
WHERE total = (
    SELECT MAX(total) FROM orders o2 WHERE o2.user_id = o1.user_id
);

-- 找出超过用户平均订单金额的订单
SELECT * FROM orders o1
WHERE total > (
    SELECT AVG(total) FROM orders o2 WHERE o2.user_id = o1.user_id
);
```

## 7. 实战练习

### 练习 1：子查询综合

```sql
-- 找出销量超过平均的商品
SELECT
    p.id,
    p.name,
    p.category,
    p.price,
    COALESCE(SUM(oi.quantity), 0) AS total_sold,
    p.price * COALESCE(SUM(oi.quantity), 0) AS revenue
FROM products p
LEFT JOIN order_items oi ON p.id = oi.product_id
GROUP BY p.id, p.name, p.category, p.price
HAVING COALESCE(SUM(oi.quantity), 0) > (
    SELECT AVG(sold_count)
    FROM (
        SELECT COUNT(oi2.quantity) AS sold_count
        FROM order_items oi2
        GROUP BY oi2.product_id
    ) AS sales
)
ORDER BY revenue DESC;
```

### 练习 2：复杂报表

```sql
-- 用户购买力分析
SELECT
    u.username,
    u.email,
    COALESCE(order_stats.order_count, 0) AS order_count,
    COALESCE(order_stats.total_spent, 0) AS total_spent,
    COALESCE(order_stats.avg_order, 0) AS avg_order,
    CASE
        WHEN COALESCE(order_stats.total_spent, 0) > 10000 THEN 'VIP'
        WHEN COALESCE(order_stats.total_spent, 0) > 5000 THEN '高级'
        WHEN COALESCE(order_stats.total_spent, 0) > 0 THEN '普通'
        ELSE '新用户'
    END AS customer_level
FROM users u
LEFT JOIN (
    SELECT
        user_id,
        COUNT(*) AS order_count,
        SUM(total) AS total_spent,
        AVG(total) AS avg_order
    FROM orders
    WHERE status = 'completed'
    GROUP BY user_id
) order_stats ON u.id = order_stats.user_id
ORDER BY total_spent DESC NULLS LAST;
```

## 今日总结

- [ ] 子查询是嵌套在主查询中的查询
- [ ] 标量子查询返回单个值，用于 SELECT 或 WHERE
- [ ] 列子查询返回一列值，用于 WHERE IN
- [ ] `ANY/SOME` 任一满足，`ALL` 全部满足
- [ ] 表子查询作为临时表用于 FROM
- [ ] `EXISTS` 检查子查询是否返回行
- [ ] 相关子查询引用外查询的列，逐行执行

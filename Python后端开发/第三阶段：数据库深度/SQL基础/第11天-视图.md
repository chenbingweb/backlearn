## 1. 视图基础

### 什么是视图

视图（View）是基于 SQL 查询结果的虚拟表，不存储实际数据。

```sql
-- 创建视图
CREATE VIEW active_users AS
SELECT id, username, email
FROM users
WHERE is_active = TRUE;

-- 使用视图如同使用表
SELECT * FROM active_users;
SELECT * FROM active_users WHERE username LIKE 'a%';
```

### 视图 vs 表

| 特性 | 视图 | 表 |
|------|------|-----|
| 存储数据 | 否（只存储查询） | 是 |
| 占用空间 | 否 | 是 |
| 数据更新 | 有限制 | 完全支持 |
| 索引 | 不能直接建 | 可以 |
| 简化查询 | 是 | 否 |

## 2. 创建视图

### 基本语法

```sql
-- 简单视图
CREATE VIEW user_emails AS
SELECT id, username, email
FROM users;

-- 带计算列
CREATE VIEW order_summaries AS
SELECT
    o.id,
    o.order_no,
    u.username,
    o.total,
    o.status,
    o.created_at,
    COUNT(oi.id) AS item_count
FROM orders o
JOIN users u ON o.user_id = u.id
LEFT JOIN order_items oi ON o.id = oi.order_id
GROUP BY o.id, o.order_no, u.username, o.total, o.status, o.created_at;
```

### OR REPLACE

```sql
-- 如果视图已存在则替换
CREATE OR REPLACE VIEW active_users AS
SELECT id, username, email, created_at
FROM users
WHERE is_active = TRUE;
```

### 列别名

```sql
-- 为视图列指定别名
CREATE VIEW user_stats AS
SELECT
    u.id,
    u.username,
    COUNT(o.id) AS order_count,
    COALESCE(SUM(o.total), 0) AS total_spent,
    MAX(o.created_at) AS last_order_date
FROM users u
LEFT JOIN orders o ON u.id = o.user_id
GROUP BY u.id, u.username;
```

## 3. 查看和删除视图

### 查看视图

```sql
-- PostgreSQL
\dv                          -- 列出所有视图
\d view_name                 -- 查看视图结构
SELECT viewname FROM pg_views WHERE schemaname = 'public';

-- MySQL
SHOW FULL TABLES WHERE Table_type = 'VIEW';
SHOW CREATE VIEW view_name;
```

### 删除视图

```sql
-- 删除视图
DROP VIEW user_emails;

-- 如果存在才删除
DROP VIEW IF EXISTS user_emails;
```

## 4. 可更新视图

### 可更新条件

```sql
-- 可更新视图必须：
-- 1. 来自单个表
-- 2. 包含所有 NOT NULL 列
-- 3. 不含聚合、GROUP BY、DISTINCT、HAVING、UNION
```

### INSERT/UPDATE/DELETE

```sql
-- 创建可更新视图
CREATE VIEW simple_users AS
SELECT id, username, email
FROM users
WHERE is_active = TRUE;

-- 通过视图插入数据
INSERT INTO simple_users (username, email) VALUES ('alice', 'alice@test.com');
-- 等价于向 users 表插入

-- 通过视图更新数据
UPDATE simple_users SET email = 'new@test.com' WHERE username = 'alice';

-- 通过视图删除数据
DELETE FROM simple_users WHERE username = 'alice';
```

### WITH CHECK OPTION

```sql
-- 防止通过视图插入/更新不满足 WHERE 条件的数据
CREATE VIEW active_users AS
SELECT id, username, email
FROM users
WHERE is_active = TRUE
WITH CHECK OPTION;

-- ❌ 错误：会违反 WHERE 条件
INSERT INTO active_users (username, email, is_active) VALUES ('bob', 'bob@test.com', FALSE);
-- 错误：WITH CHECK OPTION 阻止了插入

-- ✅ 正确
INSERT INTO active_users (username, email, is_active) VALUES ('bob', 'bob@test.com', TRUE);
```

## 5. 物化视图（PostgreSQL）

### 基本概念

物化视图是实际存储查询结果的视图，定期刷新数据。

```sql
-- 创建物化视图
CREATE MATERIALIZED VIEW monthly_sales AS
SELECT
    DATE_TRUNC('month', created_at) AS month,
    COUNT(*) AS order_count,
    SUM(total) AS total_sales,
    AVG(total) AS avg_order_value
FROM orders
WHERE status = 'completed'
GROUP BY DATE_TRUNC('month', created_at)
ORDER BY month DESC;

-- 查询物化视图
SELECT * FROM monthly_sales;
```

### 刷新物化视图

```sql
-- 手动刷新
REFRESH MATERIALIZED VIEW monthly_sales;

-- 并发刷新（不阻塞查询）
REFRESH MATERIALIZED VIEW CONCURRENTLY monthly_sales;

-- 自动刷新（需要扩展 pg_cron）
```

### 物化视图索引

```sql
-- 为物化视图创建索引
CREATE INDEX ON monthly_sales(month);
```

## 6. 视图应用场景

### 简化复杂查询

```sql
-- 创建订单详情视图
CREATE VIEW order_details AS
SELECT
    o.id,
    o.order_no,
    u.username,
    u.email,
    p.name AS product_name,
    oi.quantity,
    oi.price,
    oi.quantity * oi.price AS subtotal,
    o.total,
    o.status,
    o.created_at
FROM orders o
JOIN users u ON o.user_id = u.id
JOIN order_items oi ON o.id = oi.order_id
JOIN products p ON oi.product_id = p.id;

-- 使用视图简化查询
SELECT * FROM order_details WHERE order_no = 'ORD202401010001';
SELECT * FROM order_details WHERE username = 'alice';
```

### 数据安全

```sql
-- 只暴露需要的列
CREATE VIEW public_user_info AS
SELECT id, username, created_at
FROM users;

-- 授权给其他用户
GRANT SELECT ON public_user_info TO readonly_user;

-- 不暴露敏感信息
CREATE VIEW safe_orders AS
SELECT order_no, total, status, created_at
FROM orders;
-- 不暴露 user_id 等敏感信息
```

## 7. 实战练习

### 练习 1：销售报表视图

```sql
-- 创建月销售报表视图
CREATE VIEW monthly_report AS
SELECT
    TO_CHAR(o.created_at, 'YYYY-MM') AS month,
    COUNT(DISTINCT o.user_id) AS customer_count,
    COUNT(o.id) AS order_count,
    SUM(o.total) AS total_revenue,
    AVG(o.total) AS avg_order_value,
    SUM(oi.quantity) AS item_sold
FROM orders o
LEFT JOIN order_items oi ON o.id = oi.order_id
WHERE o.status = 'completed'
GROUP BY TO_CHAR(o.created_at, 'YYYY-MM')
ORDER BY month DESC;

-- 查询
SELECT * FROM monthly_report WHERE month >= '2024-01';
```

### 练习 2：用户画像视图

```sql
-- 创建用户画像视图
CREATE VIEW user_profiles AS
SELECT
    u.id,
    u.username,
    u.email,
    u.created_at AS member_since,
    COALESCE(order_stats.order_count, 0) AS total_orders,
    COALESCE(order_stats.total_spent, 0) AS lifetime_value,
    COALESCE(order_stats.avg_order, 0) AS avg_order_value,
    COALESCE(product_stats.product_count, 0) AS product_types,
    COALESCE(product_stats.total_items, 0) AS total_items,
    CASE
        WHEN COALESCE(order_stats.total_spent, 0) > 10000 THEN 'VIP'
        WHEN COALESCE(order_stats.total_spent, 0) > 5000 THEN 'Premium'
        WHEN COALESCE(order_stats.total_spent, 0) > 0 THEN 'Regular'
        ELSE 'New'
    END AS customer_tier
FROM users u
LEFT JOIN (
    SELECT
        user_id,
        COUNT(*) AS order_count,
        SUM(total) AS total_spent,
        AVG(total) AS avg_order
    FROM orders
    WHERE status = 'completed'
    GROUP BY user_id
) order_stats ON u.id = order_stats.user_id
LEFT JOIN (
    SELECT
        o.user_id,
        COUNT(DISTINCT oi.product_id) AS product_count,
        SUM(oi.quantity) AS total_items
    FROM orders o
    JOIN order_items oi ON o.id = oi.order_id
    WHERE o.status = 'completed'
    GROUP BY o.user_id
) product_stats ON u.id = product_stats.user_id;
```

## 今日总结

- [ ] 视图是基于 SQL 查询的虚拟表，不存储实际数据
- [ ] `CREATE VIEW` 创建视图，`DROP VIEW` 删除
- [ ] `CREATE OR REPLACE` 替换已存在的视图
- [ ] 简单视图（单表、无聚合）可以更新
- [ ] `WITH CHECK OPTION` 防止违反 WHERE 条件的数据写入
- [ ] 物化视图存储实际数据，需手动或定时刷新
- [ ] 视图用于简化查询、保护数据安全

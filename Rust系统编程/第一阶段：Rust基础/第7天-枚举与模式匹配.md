## 1. 枚举 Enum

### 基本枚举

```rust
enum Direction {
    North,
    South,
    East,
    West,
}

fn main() {
    let dir = Direction::North;

    match dir {
        Direction::North => println!("北"),
        Direction::South => println!("南"),
        Direction::East => println!("东"),
        Direction::West => println!("西"),
    }
}
```

### 枚举 vs 结构体

```
结构体：一种类型，多个字段
  struct User { name: String, age: u32 }

枚举：一种类型，多种可能
  enum Message { Quit, Move { x: i32, y: i32 }, Write(String) }
```

## 2. 带数据的枚举变体

### 枚举变体携带数据

```rust
enum Message {
    Quit,                           // 无数据
    Move { x: i32, y: i32 },        // 匿名结构体
    Write(String),                  // 单个值
    ChangeColor(i32, i32, i32),     // 多个值
}

fn main() {
    let msg1 = Message::Quit;
    let msg2 = Message::Move { x: 10, y: 20 };
    let msg3 = Message::Write(String::from("hello"));
    let msg4 = Message::ChangeColor(255, 0, 0);
}
```

### 为枚举定义方法

```rust
impl Message {
    fn call(&self) {
        match self {
            Message::Quit => println!("退出"),
            Message::Move { x, y } => println!("移动到 ({}, {})", x, y),
            Message::Write(text) => println!("写入: {}", text),
            Message::ChangeColor(r, g, b) => {
                println!("改颜色 RGB({}, {}, {})", r, g, b)
            }
        }
    }
}

fn main() {
    let msg = Message::Move { x: 10, y: 20 };
    msg.call();
}
```

## 3. Option 枚举

### 定义

```rust
enum Option<T> {
    Some(T),
    None,
}
```

`Option` 表示一个值可能存在也可能不存在，替代了其他语言中的 `null`。

### 使用 Option

```rust
fn main() {
    let some_number = Some(5);
    let some_string = Some("hello");
    let absent_number: Option<i32> = None;

    // 从 Option 中取值
    match some_number {
        Some(n) => println!("数字: {}", n),
        None => println!("没有数字"),
    }
}
```

### Option 不能直接与值运算

```rust
fn main() {
    let x: i8 = 5;
    let y: Option<i8> = Some(5);

    // let sum = x + y;  // ❌ 错误！不能相加
    // 必须先解包
}
```

### unwrap 系列方法

```rust
fn main() {
    let some = Some(5);

    // unwrap：直接取值，None 会 panic
    let n = some.unwrap();           // 5
    // let n = None.unwrap();        // panic!

    // unwrap_or：提供默认值
    let n = None.unwrap_or(0);       // 0

    // unwrap_or_else：默认值用闭包计算
    let n = None.unwrap_or_else(|| 0);

    // expect：自定义 panic 消息
    let n = some.expect("应该有值");  // 5
}
```

## 4. Result 枚举

### 定义

```rust
enum Result<T, E> {
    Ok(T),
    Err(E),
}
```

`Result` 用于可能失败的操作。

### 使用 Result

```rust
use std::fs::File;

fn main() {
    let f = File::open("hello.txt");

    match f {
        Ok(file) => println!("文件打开成功: {:?}", file),
        Err(error) => println!("打开失败: {}", error),
    }
}
```

### 简化处理

```rust
fn main() {
    let f = File::open("hello.txt");

    // unwrap
    // let f = f.unwrap();  // 失败会 panic

    // expect
    // let f = f.expect("无法打开 hello.txt");  // 失败 panic + 自定义消息
}
```

## 5. match 表达式深入

### 基本 match

```rust
fn main() {
    let number = 3;

    match number {
        1 => println!("一"),
        2 => println!("二"),
        3 => println!("三"),
        _ => println!("其他"),  // 通配符，匹配所有剩余情况
    }
}
```

### 匹配多个模式

```rust
match number {
    1 | 2 => println!("一或二"),    // 或
    3..=5 => println!("三到五"),     // 范围
    _ => println!("其他"),
}
```

### 解构枚举

```rust
enum Message {
    Quit,
    Move { x: i32, y: i32 },
    Write(String),
}

fn process_msg(msg: Message) {
    match msg {
        Message::Quit => println!("退出"),
        Message::Move { x, y } => println!("移动: {}, {}", x, y),
        Message::Write(text) => println!("文本: {}", text),
    }
}
```

### 解构结构体

```rust
struct Point { x: i32, y: i32 }

fn main() {
    let p = Point { x: 0, y: 7 };

    match p {
        Point { x, y: 0 } => println!("在 x 轴上, x={}", x),
        Point { x: 0, y } => println!("在 y 轴上, y={}", y),
        Point { x, y } => println!("任意点: {}, {}", x, y),
    }
}
```

### 解构元组和嵌套

```rust
fn main() {
    let ((a, b), Point { x, y }) = ((1, 2), Point { x: 3, y: 4 });
    println!("a={}, b={}, x={}, y={}", a, b, x, y);
}
```

### 忽略值

```rust
match some_value {
    (1, _, _) => println!("第一个是 1"),
    (_, 2, _) => println!("第二个是 2"),
    _ => println!("其他"),
}
```

### 绑定值

```rust
match msg {
    Message::Move { x, y } => {
        println!("移动: x={}, y={}", x, y);
    }
    // 用 @ 绑定整个值
    msg @ Message::Write(_) => {
        println!("完整消息: {:?}", msg);
    }
    _ => {}
}
```

### match 必须是穷尽的

```rust
match Some(5) {
    Some(n) => println!("{}", n),
    // None => ...  // 如果不写，编译器会报错！
}
```

## 6. if let 简化

### 只关心一种模式

```rust
// 用 match
match some_option {
    Some(n) => println!("{}", n),
    _ => {},
}

// 用 if let 更简洁
if let Some(n) = some_option {
    println!("{}", n);
}
```

### if let else

```rust
let config_max = Some(3u8);

if let Some(max) = config_max {
    println!("最大值: {}", max);
} else {
    println!("没有最大值");
}
```

## 7. while let

```rust
let mut stack = Vec::new();
stack.push(1);
stack.push(2);
stack.push(3);

// 只要 pop 返回 Some，就继续
while let Some(top) = stack.pop() {
    println!("弹出: {}", top);
}
// 输出: 3, 2, 1
```

## 实战练习

### 练习 1：实现一个简单的状态机

```rust
enum State {
    Idle,
    Running { speed: u32 },
    Paused { progress: f64 },
    Stopped { completed: bool },
}

impl State {
    fn description(&self) -> String {
        match self {
            State::Idle => String::from("空闲"),
            State::Running { speed } => format!("运行中，速度: {}", speed),
            State::Paused { progress } => format!("已暂停，进度: {:.1}%", progress * 100.0),
            State::Stopped { completed } => {
                if *completed {
                    String::from("已完成")
                } else {
                    String::from("已停止")
                }
            }
        }
    }
}

fn main() {
    let states = vec![
        State::Idle,
        State::Running { speed: 100 },
        State::Paused { progress: 0.5 },
        State::Stopped { completed: true },
    ];

    for state in states {
        println!("{}", state.description());
    }
}
```

### 练习 2：使用 Option

```rust
fn divide(numerator: f64, denominator: f64) -> Option<f64> {
    if denominator == 0.0 {
        None
    } else {
        Some(numerator / denominator)
    }
}

fn main() {
    let result = divide(10.0, 2.0);
    match result {
        Some(x) => println!("结果: {}", x),
        None => println!("不能除以零"),
    }

    // 更简洁的方式
    if let Some(x) = divide(10.0, 0.0) {
        println!("结果: {}", x);
    } else {
        println!("不能除以零");
    }
}
```

### 练习 3：硬币找零

```rust
enum Coin {
    Penny,
    Nickel,
    Dime,
    Quarter { state: String },  // 25美分，带州名
}

fn value_in_cents(coin: &Coin) -> u8 {
    match coin {
        Coin::Penny => {
            println!("幸运币！");
            1
        }
        Coin::Nickel => 5,
        Coin::Dime => 10,
        Coin::Quarter { state } => {
            println!("来自 {} 州的25美分！", state);
            25
        }
    }
}

fn main() {
    let coins = vec![
        Coin::Penny,
        Coin::Quarter { state: String::from("Alaska") },
        Coin::Dime,
    ];

    let total: u8 = coins.iter().map(value_in_cents).sum();
    println!("总价值: {} 美分", total);
}
```

## 今日总结

- [ ] 枚举用 `enum` 定义，可以有多个变体
- [ ] 枚举变体可以携带数据：匿名结构体、元组、单个值
- [ ] `Option<T>` 表示有值（`Some`）或无值（`None`），替代 null
- [ ] `Result<T, E>` 表示成功（`Ok`）或失败（`Err`）
- [ ] `match` 必须穷尽所有可能，用 `_` 作为通配符
- [ ] `if let` 只匹配一种模式，代码更简洁
- [ ] `while let` 在条件匹配时循环
- [ ] 模式中可以解构结构体、枚举、元组、数组
- [ ] `@` 绑定可以获取整个值

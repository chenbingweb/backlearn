## 1. 结构体 Struct

### 定义结构体

```rust
struct User {
    username: String,
    email: String,
    sign_in_count: u64,
    active: bool,
}
```

### 创建实例

```rust
fn main() {
    let user1 = User {
        username: String::from("alice"),
        email: String::from("alice@example.com"),
        active: true,
        sign_in_count: 1,
    };

    // 访问字段
    println!("用户名: {}", user1.username);
    println!("邮箱: {}", user1.email);
}
```

### 可变结构体

```rust
fn main() {
    let mut user1 = User {
        username: String::from("alice"),
        email: String::from("alice@example.com"),
        active: true,
        sign_in_count: 1,
    };

    // 修改字段
    user1.email = String::from("new@example.com");
    user1.sign_in_count += 1;
}
```

注意：**整个结构体必须是可变的**，不能只让某个字段可变。

### 简化创建：字段初始化简写

```rust
fn build_user(email: String, username: String) -> User {
    User {
        email,       // 等价于 email: email
        username,    // 等价于 username: username
        active: true,
        sign_in_count: 1,
    }
}
```

### 从其他实例创建：结构体更新语法

```rust
fn main() {
    let user1 = User {
        username: String::from("alice"),
        email: String::from("alice@example.com"),
        active: true,
        sign_in_count: 1,
    };

    // 大部分字段和 user1 相同，只改 email
    let user2 = User {
        email: String::from("bob@example.com"),
        ..user1      // 其余字段从 user1 获取
    };

    // 注意：user1 的 username 被移动到 user2 了！
    // println!("{}", user1.username);  // ❌ 已移动
    println!("{}", user1.sign_in_count);  // ✅ 标量类型，Copy
}
```

## 2. 元组结构体

### 没有字段名的结构体

```rust
struct Point(i32, i32, i32);     // 三维坐标
struct Color(i32, i32, i32);     // RGB 颜色

fn main() {
    let origin = Point(0, 0, 0);
    let black = Color(0, 0, 0);

    // 通过索引访问
    println!("x = {}", origin.0);
    println!("y = {}", origin.1);
}
```

元组结构体适合有名字但字段含义明确、不需要命名的场景。

## 3. 单元结构体

## 4. 方法

### 定义方法

```rust
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    // 方法：第一个参数是 self
    fn area(&self) -> u32 {
        self.width * self.height
    }

    // 可以借用可变 self
    fn scale(&mut self, factor: u32) {
        self.width *= factor;
        self.height *= factor;
    }

    // 转移所有权
    fn destroy(self) {
        println!("销毁了一个 {:?}", self);
    }
}

fn main() {
    let rect = Rectangle {
        width: 30,
        height: 50,
    };

    println!("面积: {}", rect.area());  // 自动引用
}
```

### self 的三种形式

| 形式 | 说明 |
|------|------|
| `self` | 获取所有权，调用后原变量不可用 |
| `&self` | 不可变借用，只读 |
| `&mut self` | 可变借用，可修改 |

```rust
impl Rectangle {
    fn consume(self) { }           // 获取所有权
    fn read(&self) { }             // 不可变借用
    fn write(&mut self) { }        // 可变借用
}
```

### 自动引用和解引用

```rust
fn main() {
    let rect = Rectangle { width: 30, height: 50 };

    // 以下等价
    println!("{}", rect.area());       // 自动转 &rect
    println!("{}", (&rect).area());     // 显式借用
}
```

Rust 会自动添加 `&`、`*`、或 `&mut`。

## 5. 关联函数

### 没有 self 参数的函数

```rust
impl Rectangle {
    // 关联函数（不是方法）
    fn square(size: u32) -> Rectangle {
        Rectangle {
            width: size,
            height: size,
        }
    }

    // 构造函数风格
    fn new(width: u32, height: u32) -> Rectangle {
        Rectangle { width, height }
    }
}

fn main() {
    // 用 :: 调用关联函数
    let sq = Rectangle::square(30);
    let rect = Rectangle::new(30, 50);
}
```

对比：
- **方法**：`rect.area()` — 作用于实例
- **关联函数**：`Rectangle::square(30)` — 类似静态方法

## 6. 多个 impl 块

```rust
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    fn area(&self) -> u32 {
        self.width * self.height
    }
}

impl Rectangle {
    fn can_hold(&self, other: &Rectangle) -> bool {
        self.width > other.width && self.height > other.height
    }
}
```

每个结构体可以有多个 `impl` 块，常用于分离不同 Trait 的实现。

## 实战练习

### 练习 1：实现一个 Circle

```rust
struct Circle {
    radius: f64,
}

impl Circle {
    fn new(radius: f64) -> Circle {
        Circle { radius }
    }

    fn area(&self) -> f64 {
        std::f64::consts::PI * self.radius * self.radius
    }

    fn circumference(&self) -> f64 {
        2.0 * std::f64::consts::PI * self.radius
    }

    fn scale(&mut self, factor: f64) {
        self.radius *= factor;
    }
}

fn main() {
    let mut circle = Circle::new(5.0);
    println!("面积: {:.2}", circle.area());
    println!("周长: {:.2}", circle.circumference());

    circle.scale(2.0);
    println!("放大后面积: {:.2}", circle.area());
}
```

### 练习 2：实现一个银行账户

```rust
struct BankAccount {
    owner: String,
    balance: f64,
}

impl BankAccount {
    fn new(owner: &str, initial_balance: f64) -> BankAccount {
        BankAccount {
            owner: String::from(owner),
            balance: initial_balance,
        }
    }

    fn deposit(&mut self, amount: f64) {
        if amount > 0.0 {
            self.balance += amount;
            println!("存入 {}, 余额: {}", amount, self.balance);
        }
    }

    fn withdraw(&mut self, amount: f64) -> bool {
        if amount > 0.0 && self.balance >= amount {
            self.balance -= amount;
            println!("取出 {}, 余额: {}", amount, self.balance);
            true
        } else {
            println!("余额不足或金额无效");
            false
        }
    }

    fn balance(&self) -> f64 {
        self.balance
    }
}

fn main() {
    let mut account = BankAccount::new("Alice", 1000.0);
    account.deposit(500.0);
    account.withdraw(200.0);
    println!("当前余额: {}", account.balance());
}
```

### 练习 3：Rectangle 扩展

```rust
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    fn new(width: u32, height: u32) -> Rectangle {
        Rectangle { width, height }
    }

    fn area(&self) -> u32 {
        self.width * self.height
    }

    fn perimeter(&self) -> u32 {
        2 * (self.width + self.height)
    }

    fn is_square(&self) -> bool {
        self.width == self.height
    }

    fn can_hold(&self, other: &Rectangle) -> bool {
        self.width >= other.width && self.height >= other.height
    }

    fn scale(&mut self, factor: u32) {
        self.width *= factor;
        self.height *= factor;
    }
}

fn main() {
    let rect1 = Rectangle::new(30, 50);
    let rect2 = Rectangle::new(10, 20);

    println!("面积: {}", rect1.area());
    println!("周长: {}", rect1.perimeter());
    println!("是正方形: {}", rect1.is_square());
    println!("能装下 rect2: {}", rect1.can_hold(&rect2));
}
```

## 今日总结

- [ ] 结构体用 `struct` 定义，包含命名字段
- [ ] 创建实例时用 `{ field: value }`，字段顺序不重要
- [ ] `..other` 语法从其他实例复制剩余字段
- [ ] 元组结构体 `struct Point(i32, i32)` 没有字段名
- [ ] 单元结构体 `struct Empty;` 没有任何字段
- [ ] 方法在 `impl` 块中定义，第一个参数是 `self`
- [ ] `&self` 不可变借用，`&mut self` 可变借用，`self` 获取所有权
- [ ] 关联函数没有 `self` 参数，用 `::` 调用
- [ ] 自动引用：`rect.area()` 等价于 `(&rect).area()`

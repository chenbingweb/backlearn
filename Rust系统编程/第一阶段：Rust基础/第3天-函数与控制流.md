## 1. 函数

### 函数定义

```rust
fn main() {
    println!("Hello!");
    another_function();
}

fn another_function() {
    println!("另一个函数");
}
```

### 函数参数

```rust
fn main() {
    print_number(5);
    print_sum(3, 4);
}

fn print_number(x: i32) {
    println!("数字: {}", x);
}

fn print_sum(a: i32, b: i32) {
    println!("{} + {} = {}", a, b, a + b);
}
```

### 返回值

```rust
fn main() {
    let x = five();
    println!("x = {}", x);  // x = 5

    let y = plus_one(5);
    println!("y = {}", y);  // y = 6
}

// 返回 i32
fn five() -> i32 {
    5  // 没有分号！这是表达式
}

fn plus_one(x: i32) -> i32 {
    x + 1  // 没有分号，返回值
}
```

### 语句 vs 表达式

```rust
fn main() {
    // 语句（statement）：执行动作，不返回值
    let x = 5;     // let 是语句

    // 表达式（expression）：返回值
    let y = {
        let a = 3;
        a + 1       // 这是表达式，返回 4
    };              // y = 4

    // ❌ 错误：语句不能赋值
    // let x = (let y = 5);
}
```

关键规则：**表达式末尾没有分号，就是返回值**。

### 提前返回

```rust
fn divide(a: f64, b: f64) -> f64 {
    if b == 0.0 {
        return f64::NAN;  // 提前返回
    }
    a / b
}
```

## 2. 控制流

### if 表达式

```rust
fn main() {
    let number = 6;

    if number < 5 {
        println!("小于 5");
    } else if number < 10 {
        println!("5 到 10 之间");
    } else {
        println!("大于等于 10");
    }
}
```

### if 是表达式，可以赋值

```rust
fn main() {
    let condition = true;
    let number = if condition { 5 } else { 6 };
    println!("number = {}", number);  // 5

    // 两个分支必须返回相同类型
    // let x = if condition { 5 } else { "six" };  // ❌ 错误
}
```

### loop 无限循环

```rust
fn main() {
    let mut count = 0;

    loop {
        println!("count = {}", count);
        count += 1;

        if count >= 5 {
            break;  // 跳出循环
        }
    }
}
```

### loop 返回值

```rust
fn main() {
    let result = loop {
        // 做一些计算...
        break 10;  // break 可以返回值
    };
    println!("result = {}", result);  // 10
}
```

### 循环标签

```rust
fn main() {
    let mut count = 0;

    'counting_up: loop {
        println!("count = {}", count);
        let mut remaining = 10;

        loop {
            println!("remaining = {}", remaining);
            if remaining == 9 {
                break;  // 跳出内层循环
            }
            if count == 2 {
                break 'counting_up;  // 跳出外层循环
            }
            remaining -= 1;
        }
        count += 1;
    }
}
```

### while 条件循环

```rust
fn main() {
    let mut number = 3;

    while number != 0 {
        println!("{}!", number);
        number -= 1;
    }
    println!("发射!");
}
```

### for 遍历

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];

    // 遍历数组
    for element in a {
        println!("值为: {}", element);
    }

    // 遍历范围（1到4，不包括5）
    for number in 1..5 {
        println!("{}", number);  // 1 2 3 4
    }

    // 包含 5
    for number in 1..=5 {
        println!("{}", number);  // 1 2 3 4 5
    }

    // 反转
    for number in (1..4).rev() {
        println!("{}!", number);  // 3 2 1
    }
}
```

### continue 跳过

```rust
fn main() {
    for number in 1..=10 {
        if number % 2 == 0 {
            continue;  // 跳过偶数
        }
        println!("奇数: {}", number);
    }
}
```

## 3. match 基础

```rust
fn main() {
    let number = 3;

    match number {
        1 => println!("一"),
        2 => println!("二"),
        3 => println!("三"),
        _ => println!("其他"),  // 通配符
    }
}
```

match 要求**穷尽所有情况**。

## 实战练习

### 练习 1：斐波那契数列

```rust
fn main() {
    let n = 10;
    println!("斐波那契数列前 {} 项:", n);

    let mut a = 0;
    let mut b = 1;

    for _ in 0..n {
        print!("{} ", a);
        let temp = a + b;
        a = b;
        b = temp;
    }
    println!();
}
```

### 练习 2：猜数字游戏（基础版）

```rust
use std::io;

fn main() {
    println!("猜一个 1-100 之间的数字！");
    let secret = 42;

    loop {
        println!("请输入你的猜测:");

        let mut guess = String::new();
        io::stdin()
            .read_line(&mut guess)
            .expect("读取失败");

        let guess: i32 = match guess.trim().parse() {
            Ok(num) => num,
            Err(_) => {
                println!("请输入数字！");
                continue;
            }
        };

        match guess.cmp(&secret) {
            std::cmp::Ordering::Less => println!("太小了！"),
            std::cmp::Ordering::Greater => println!("太大了！"),
            std::cmp::Ordering::Equal => {
                println!("恭喜你，猜对了！");
                break;
            }
        }
    }
}
```

### 练习 3：判断闰年

```rust
fn is_leap_year(year: i32) -> bool {
    (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)
}

fn main() {
    let years = [1900, 2000, 2004, 2019, 2020];

    for year in years {
        if is_leap_year(year) {
            println!("{} 是闰年", year);
        } else {
            println!("{} 不是闰年", year);
        }
    }
}
```

### 练习 4：计算阶乘

```rust
fn factorial(n: u64) -> u64 {
    if n == 0 || n == 1 {
        return 1;
    }
    n * factorial(n - 1)
}

fn main() {
    for i in 0..=10 {
        println!("{}! = {}", i, factorial(i));
    }
}
```

## 今日总结

- [ ] 函数用 `fn` 定义，参数必须标注类型
- [ ] 返回值用 `-> Type`，最后一个表达式就是返回值（不加 `;`）
- [ ] 语句不返回值，表达式返回值；`let` 是语句
- [ ] `if` 是表达式，可以赋值给变量
- [ ] `loop` 无限循环，`break` 可返回值
- [ ] 循环标签 `'label:` 用于跳出指定层
- [ ] `for` 配合范围 `1..5`（不含5）或 `1..=5`（含5）
- [ ] `match` 要求穷尽所有分支

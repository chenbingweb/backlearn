## 1. 核心概念

### Crate、Package、Module

```
Package（项目包）
  └── 包含一个或多个 Crate
      └── Crate（编译单元）
          └── 包含 Module 树
              └── Module（代码组织单元）
```

- **Package**：一个 Cargo 项目，包含 `Cargo.toml`
- **Crate**：编译的最小单元，可以是二进制（bin）或库（lib）
- **Module**：代码分组和封装，控制可见性

## 2. 创建 Crate

### 二进制 Crate

```bash
cargo new my_app        # 默认创建二进制项目
# 结构：
# my_app/
# ├── Cargo.toml
# └── src/
#     └── main.rs       # 二进制入口
```

### 库 Crate

```bash
cargo new my_lib --lib
# 结构：
# my_lib/
# ├── Cargo.toml
# └── src/
#     └── lib.rs        # 库入口
```

### 一个 Package 多个 Crate

```
my_project/
├── Cargo.toml
└── src/
    ├── main.rs         # 默认二进制 crate
    ├── lib.rs          # 库 crate
    └── bin/
        ├── server.rs   # 额外二进制: cargo run --bin server
        └── client.rs   # 额外二进制: cargo run --bin client
```

## 3. 模块系统

### 定义模块

```rust
// src/lib.rs
mod front_of_house {
    pub mod hosting {           // pub 表示公开
        pub fn add_to_waitlist() {
            println!("添加等待");
        }

        fn seat_at_table() {    // 默认私有
            println!("安排座位");
        }
    }

    mod serving {               // 私有模块
        pub fn take_order() {}
        fn serve_order() {}
    }
}
```

### 可见性规则

```rust
mod outer {
    pub fn public_fn() {}       // 公开
    fn private_fn() {}          // 私有（默认）

    pub mod inner {
        pub fn deep_fn() {}     // 模块公开 + 函数公开 = 可用
        fn hidden_fn() {}       // 函数私有
    }
}
```

| 修饰 | 说明 |
|------|------|
| 无 | 私有，仅当前模块及子模块可用 |
| `pub` | 公开，任何地方可用 |
| `pub(crate)` | 整个 crate 内可见 |
| `pub(super)` | 父模块可见 |
| `pub(in path)` | 指定路径可见 |

### 引用模块

```rust
// 绝对路径
 crate::front_of_house::hosting::add_to_waitlist();

// 相对路径
 front_of_house::hosting::add_to_waitlist();

// super 引用父模块
super::some_function();
```

## 4. use 关键字

### 引入模块

```rust
// src/lib.rs
mod front_of_house {
    pub mod hosting {
        pub fn add_to_waitlist() {}
    }
}

// 使用 use 引入
use crate::front_of_house::hosting;

pub fn eat_at_restaurant() {
    hosting::add_to_waitlist();  // 直接使用
}
```

### 引入函数

```rust
use crate::front_of_house::hosting::add_to_waitlist;

pub fn eat() {
    add_to_waitlist();  // 直接调用
}
```

**惯例**：引入模块（`use crate::hosting`）比引入函数（`use crate::hosting::add_to_waitlist`）更清晰。

### 重命名

```rust
use std::fmt::Result as FmtResult;
use std::io::Result as IoResult;

fn fmt_func() -> FmtResult { Ok(()) }
fn io_func() -> IoResult<String> { Ok(String::new()) }
```

### pub use 重导出

```rust
// 内部使用这个路径
use self::front_of_house::hosting;

// 对外暴露这个路径
pub use self::front_of_house::hosting;

// 外部用户可以：
// use my_crate::hosting;
```

### 嵌套路径

```rust
// 合并引入
use std::{cmp::Ordering, io, io::Write};

// 等价于
use std::cmp::Ordering;
use std::io;
use std::io::Write;

// 通配符引入（谨慎使用）
use std::collections::*;
```

## 5. 文件即模块

### 目录结构

```
src/
├── main.rs           # 入口
├── lib.rs            # 库入口
├── front_of_house.rs # 模块文件
└── front_of_house/   # 模块子目录
    ├── hosting.rs    # hosting 子模块
    └── serving.rs    # serving 子模块
```

### main.rs / lib.rs

```rust
// src/lib.rs

// 声明模块，Rust 会查找：
// 1. front_of_house.rs
// 2. front_of_house/mod.rs（旧方式）
mod front_of_house;

pub use crate::front_of_house::hosting;

pub fn eat_at_restaurant() {
    hosting::add_to_waitlist();
}
```

### front_of_house.rs

```rust
// src/front_of_house.rs

// 声明子模块，Rust 会查找：
// 1. front_of_house/hosting.rs
// 2. front_of_house/serving.rs
pub mod hosting;
pub mod serving;
```

### hosting.rs

```rust
// src/front_of_house/hosting.rs

pub fn add_to_waitlist() {
    println!("添加等待名单");
}

pub fn seat_at_table() {
    println!("安排座位");
}
```

## 6. 工作空间 Workspace

### 目录结构

```
my_workspace/
├── Cargo.toml          # 工作空间配置
├── adder/              # 二进制 crate
│   ├── Cargo.toml
│   └── src/main.rs
├── add-one/            # 库 crate
│   ├── Cargo.toml
│   └── src/lib.rs
└── add-two/            # 另一个库 crate
    ├── Cargo.toml
    └── src/lib.rs
```

### 根 Cargo.toml

```toml
[workspace]
members = [
    "adder",
    "add-one",
    "add-two",
]

# 可选：共享依赖
[workspace.dependencies]
rand = "0.8"
```

### 依赖本地 Crate

```toml
# adder/Cargo.toml
[package]
name = "adder"
version = "0.1.0"

[dependencies]
add-one = { path = "../add-one" }
```

### 工作空间命令

```bash
# 构建整个工作空间
cargo build

# 运行特定 crate
cargo run -p adder

# 测试特定 crate
cargo test -p add-one

# 添加依赖到特定 crate
cargo add -p adder rand
```

## 实战练习

### 练习 1：创建一个数学库

```rust
// src/lib.rs
pub mod calculator;
pub mod geometry;

pub use calculator::add;
pub use geometry::Circle;
```

```rust
// src/calculator.rs
pub fn add(a: i32, b: i32) -> i32 {
    a + b
}

pub fn subtract(a: i32, b: i32) -> i32 {
    a - b
}

pub fn multiply(a: i32, b: i32) -> i32 {
    a * b
}

pub fn divide(a: i32, b: i32) -> Option<i32> {
    if b == 0 {
        None
    } else {
        Some(a / b)
    }
}
```

```rust
// src/geometry.rs
pub struct Circle {
    pub radius: f64,
}

impl Circle {
    pub fn area(&self) -> f64 {
        std::f64::consts::PI * self.radius * self.radius
    }

    pub fn circumference(&self) -> f64 {
        2.0 * std::f64::consts::PI * self.radius
    }
}

pub struct Rectangle {
    pub width: f64,
    pub height: f64,
}

impl Rectangle {
    pub fn area(&self) -> f64 {
        self.width * self.height
    }
}
```

### 练习 2：使用数学库

```rust
// examples/demo.rs
use my_math_lib::{add, calculator, geometry};

fn main() {
    println!("2 + 3 = {}", add(2, 3));
    println!("10 / 2 = {:?}", calculator::divide(10, 2));

    let circle = geometry::Circle { radius: 5.0 };
    println!("圆面积: {:.2}", circle.area());
}
```

运行：`cargo run --example demo`

## 今日总结

- [ ] Package 是 Cargo 项目，Crate 是编译单元，Module 是代码组织单元
- [ ] `mod` 声明模块，`pub` 控制可见性
- [ ] `use` 简化路径引入，`pub use` 重导出
- [ ] 文件可以表示模块：`src/module.rs` 或 `src/module/mod.rs`
- [ ] 工作空间（Workspace）管理多个相关 Crate
- [ ] 默认所有项私有，需要显式 `pub`
- [ ] 外部代码只能访问 `pub` 的模块和项
- [ ] 惯例：函数用 `use crate::module` 引入模块而非具体函数

# 第 4 天：所有权基础（上）

## 学习目标

- 理解所有权系统的核心规则
- 掌握变量作用域与内存释放
- 理解移动语义
- 区分 `Copy` 和不能 `Copy` 的类型

---

## 1. 什么是所有权

### 为什么 Rust 需要所有权

传统语言管理内存的方式：
- **GC**（Java/Go/Python）：运行时自动回收，但有性能开销
- **手动管理**（C/C++）：程序员控制，容易出错（悬空指针、重复释放、内存泄漏）

Rust 的方式：
- **编译期检查**：通过所有权规则，在编译时就确保内存安全
- **零成本抽象**：没有运行时开销

### 所有权三规则

1. **每个值都有一个所有者（owner）**
2. **同一时间只能有一个所有者**
3. **当所有者离开作用域，值会被自动释放**

## 2. 变量作用域

```rust
fn main() {
    // s 在这里不可用
    {
        let s = "hello";  // s 从此处开始有效
        println!("{}", s);
    }              // s 离开作用域，被释放
    // s 在这里不可用
}
```

栈上的数据（整数、浮点等）：
```rust
fn main() {
    let x = 5;
    {
        let y = 10;
        println!("x = {}, y = {}", x, y);
    }
    // y 已释放，但 x 仍然可用
    println!("x = {}", x);
}
```

## 3. String 类型

### 为什么需要 String

```rust
fn main() {
    let s = "hello";  // &str，字符串字面量，编译期确定，不可变
    // s.push_str(", world");  // ❌ 错误！&str 不可变
}
```

`String` 是可变、堆分配的字符串：

```rust
fn main() {
    let mut s = String::from("hello");
    s.push_str(", world!");  // ✅ 可以修改
    println!("{}", s);  // hello, world!
}
```

### String 的内存布局

```
栈                    堆
┌─────────────┐      ┌──────────────┐
│ ptr         │─────→│ h e l l o    │
│ len = 5     │      └──────────────┘
│ capacity = 5│
└─────────────┘
```

## 4. 移动语义

### 变量赋值

```rust
fn main() {
    let x = 5;
    let y = x;     // 复制值，x 仍可用
    println!("x = {}, y = {}", x, y);  // ✅
}
```

整数是简单值，存储在栈上，直接复制。

### String 的移动

```rust
fn main() {
    let s1 = String::from("hello");
    let s2 = s1;   // s1 被移动到 s2

    // println!("{}", s1);  // ❌ 错误！s1 不再有效
    println!("{}", s2);     // ✅
}
```

发生了什么？

```
移动前：                    移动后：
栈                         栈
┌─────────┐               ┌─────────┐
│ s1      │──→ 堆上的数据 │ s2      │──→ 堆上的数据
│ ptr     │               │ ptr     │
│ len=5   │               │ len=5   │
│ cap=5   │               │ cap=5   │
└─────────┘               └─────────┘
s1 有效                    s1 无效（被标记为 moved）
```

为什么？如果 s1 和 s2 都指向同一块堆内存，当它们离开作用域时会**重复释放**，导致内存错误。

Rust 的选择：**移动（move）** 所有权，而不是浅拷贝。

## 5. Clone

如果需要深拷贝：

```rust
fn main() {
    let s1 = String::from("hello");
    let s2 = s1.clone();  // 深拷贝，堆数据也被复制

    println!("s1 = {}, s2 = {}", s1, s2);  // ✅ 两者都可用
}
```

```
s1 ──→ 堆: "hello"
s2 ──→ 堆: "hello"（另一块内存）
```

`clone()` 是显式的，提醒你这是一个昂贵的操作。

## 6. Copy Trait

### 哪些类型是 Copy

实现了 `Copy` Trait 的类型，赋值时会复制而不是移动：

- 所有整数类型：`i32`、`u64` 等
- 所有浮点类型：`f32`、`f64`
- 布尔类型：`bool`
- 字符类型：`char`
- 元组（只包含 Copy 类型）：`(i32, i32)`

### Copy 规则

```rust
fn main() {
    let a = 5;
    let b = a;       // Copy，a 仍可用
    println!("a = {}, b = {}", a, b);  // ✅

    let s = String::from("hi");
    let t = s;       // Move，s 不可用
    // println!("{}", s);  // ❌
}
```

### 不能 Copy 的类型

- `String`
- `Vec<T>`
- 包含非 Copy 类型的元组：`(i32, String)`
- 自定义类型（除非显式实现）

## 7. 函数与所有权

### 值传递给函数

```rust
fn main() {
    let s = String::from("hello");
    takes_ownership(s);       // s 被移动到函数
    // println!("{}", s);     // ❌ s 不再有效

    let x = 5;
    makes_copy(x);            // x 被复制
    println!("{}", x);        // ✅ x 仍有效
}

fn takes_ownership(s: String) {
    println!("{}", s);
} // s 离开作用域，内存被释放

fn makes_copy(i: i32) {
    println!("{}", i);
} // i 是 Copy，无需释放
```

### 返回值转移所有权

```rust
fn main() {
    let s1 = gives_ownership();          // 返回值移给 s1
    let s2 = String::from("hello");
    let s3 = takes_and_gives_back(s2);   // s2 移入，返回值移给 s3

    println!("s1 = {}, s3 = {}", s1, s3);
    // println!("s2 = {}", s2);  // ❌ s2 已移动
}

fn gives_ownership() -> String {
    String::from("yours")
}

fn takes_and_gives_back(s: String) -> String {
    s  // 返回 s，所有权移出
}
```

### 问题：每次传值都要归还所有权，很麻烦

解决方案：**引用（references）** — 下一天学习。

## 实战练习

### 练习 1：所有权判断

判断以下代码是否能编译，如果不能，为什么：

```rust
fn main() {
    let s1 = String::from("hello");
    let s2 = s1;
    println!("{}", s1);  // ?
}
```

```rust
fn main() {
    let x = 10;
    let y = x;
    println!("{}", x);  // ?
}
```

```rust
fn main() {
    let s = String::from("hi");
    let s2 = s.clone();
    println!("{} {}", s, s2);  // ?
}
```

答案：❌（s1 moved）、✅（i32 Copy）、✅（clone）

### 练习 2：计算字符串长度

```rust
fn main() {
    let s = String::from("hello");
    let (s, len) = calculate_length(s);
    println!("'{}' 的长度是 {}", s, len);
}

fn calculate_length(s: String) -> (String, usize) {
    let length = s.len();
    (s, length)  // 返回元组，归还所有权
}
```

### 练习 3：理解移动

```rust
fn main() {
    let s = String::from("Rust");
    print_twice(s);   // ? 能编译吗
}

fn print_twice(s: String) {
    println!("{}", s);
    println!("{}", s);
}
```

答案：能编译！因为 `String` 没有实现 `Copy`，但它不是只能使用一次的。移动后 `s` 在新函数中仍可用，只是原变量不能用了。

## 今日总结

- [ ] 所有权是 Rust 最核心的概念，在编译期确保内存安全
- [ ] 每个值有且只有一个所有者
- [ ] 所有者离开作用域，值自动释放（`drop`）
- [ ] `String` 在堆上分配，赋值时**移动**所有权
- [ ] 简单标量类型实现了 `Copy`，赋值时**复制**
- [ ] `clone()` 显式深拷贝
- [ ] 函数参数传递遵循同样的规则：移动或复制
- [ ] 可以通过返回值转移所有权，但比较繁琐（下一天用引用解决）

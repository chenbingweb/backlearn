## 1. 变量与可变性

### 默认不可变

```rust
fn main() {
    let x = 5;
    // x = 6;  // ❌ 错误！不能修改不可变变量
    println!("x = {}", x);
}
```

### 可变变量

```rust
fn main() {
    let mut x = 5;
    println!("x = {}", x);  // x = 5
    x = 6;
    println!("x = {}", x);  // x = 6
}
```

### 变量遮蔽（Shadowing）

```rust
fn main() {
    let x = 5;
    let x = x + 1;      // 用新值遮蔽旧值
    let x = x * 2;
    println!("x = {}", x);  // x = 12

    // 可以改变类型
    let spaces = "   ";
    let spaces = spaces.len();  // 从 &str 变成 usize
}
```

遮蔽 vs 可变：
- `mut`：同一变量修改值，类型不能变
- `shadowing`：创建新变量，可以改变类型

### 常量

```rust
const MAX_POINTS: u32 = 100_000;  // 下划线作为数字分隔符

fn main() {
    println!("最大分数: {}", MAX_POINTS);
}
```

常量规则：
- 必须标注类型
- 不能用 `mut`
- 编译期确定，不能是运行时计算的值

## 2. 标量类型

### 整数类型

| 长度 | 有符号 | 无符号 |
|------|--------|--------|
| 8-bit | `i8` | `u8` |
| 16-bit | `i16` | `u16` |
| 32-bit | `i32` | `u32` |
| 64-bit | `i64` | `u64` |
| 128-bit | `i128` | `u128` |
| arch | `isize` | `usize` |

```rust
fn main() {
    let a: i32 = -42;
    let b: u64 = 100;
    let c = 98_222;          // i32（默认）
    let d = 0xff;            // 十六进制
    let e = 0o77;            // 八进制
    let f = 0b1111_0000;     // 二进制
    let g = b'A';            // u8，字节字面量
}
```

整数溢出：
- **debug 模式**：运行时 panic
- **release 模式**：截断（二进制补码环绕）
- 显式处理：`wrapping_add`、`checked_add`、`saturating_add`、`overflowing_add`

```rust
let a: u8 = 255;
let b = a.wrapping_add(1);   // b = 0
let c = a.checked_add(1);    // c = None
let d = a.saturating_add(1); // d = 255
```

### 浮点类型

```rust
fn main() {
    let x = 2.0;        // f64（默认）
    let y: f32 = 3.0;   // f32

    // 数学运算
    let sum = 5.0 + 10.0;
    let diff = 95.5 - 4.3;
    let product = 4.0 * 30.0;
    let quotient = 56.7 / 32.2;
    let remainder = 43.0 % 5.0;
}
```

### 布尔类型

```rust
fn main() {
    let t = true;
    let f: bool = false;

    if t {
        println!("是真的");
    }
}
```

### 字符类型

```rust
fn main() {
    let c = 'z';
    let heart = '❤';       // Unicode
    let cat = '🐱';        // emoji
    let japanese = '中';    // 中文

    println!("字符: {}", cat);
}
```

`char` 是 Unicode 标量值，占 4 字节。

## 3. 复合类型

### 元组 Tuple

```rust
fn main() {
    // 定义
    let tup: (i32, f64, &str) = (500, 6.4, "hi");

    // 解构
    let (x, y, z) = tup;
    println!("y = {}", y);  // y = 6.4

    // 索引访问
    let five_hundred = tup.0;
    let six_point_four = tup.1;
}
```

### 单元类型

```rust
fn main() {
    let unit = ();  // 空元组，类型也是 ()
    // 函数没有返回值时，实际返回 ()
}
```

### 数组 Array

```rust
fn main() {
    // 定义
    let a = [1, 2, 3, 4, 5];
    let b: [i32; 5] = [1, 2, 3, 4, 5];

    // 相同初始值
    let c = [3; 5];  // [3, 3, 3, 3, 3]

    // 访问
    let first = a[0];
    let second = a[1];

    // 长度
    println!("数组长度: {}", a.len());
}
```

数组特点：
- 固定长度（编译期确定）
- 元素类型相同
- 栈分配

越界访问会 panic：
```rust
let a = [1, 2, 3];
let index = 10;
let element = a[index];  // ❌ 运行时 panic！
```

### 切片 Slice

```rust
fn main() {
    let a = [1, 2, 3, 4, 5];
    let slice = &a[1..3];  // [2, 3]

    let s = "hello world";
    let hello = &s[0..5];   // "hello"
    let world = &s[6..11];  // "world"
}
```

## 4. 类型推断与注解

```rust
fn main() {
    // 编译器推断类型
    let x = 5;           // i32
    let y = 3.14;        // f64

    let v: Vec<i32> = Vec::new();
}
```

## 实战练习

### 练习 1：温度转换

```rust
fn main() {
    let celsius = 25.0;
    let fahrenheit = celsius_to_fahrenheit(celsius);
    println!("{}°C = {}°F", celsius, fahrenheit);

    let f = 77.0;
    let c = fahrenheit_to_celsius(f);
    println!("{}°F = {}°C", f, c);
}

fn celsius_to_fahrenheit(c: f64) -> f64 {
    c * 9.0 / 5.0 + 32.0
}

fn fahrenheit_to_celsius(f: f64) -> f64 {
    (f - 32.0) * 5.0 / 9.0
}
```

### 练习 2：数组操作

```rust
fn main() {
    let numbers = [10, 20, 30, 40, 50];

    // 求和
    let mut sum = 0;
    for n in numbers {
        sum += n;
    }
    println!("总和: {}", sum);

    // 求平均
    let avg = sum as f64 / numbers.len() as f64;
    println!("平均: {}", avg);

    // 找最大值
    let mut max = numbers[0];
    for n in numbers {
        if n > max {
            max = n;
        }
    }
    println!("最大值: {}", max);
}
```

### 练习 3：元组交换

```rust
fn main() {
    let mut a = 5;
    let mut b = 10;
    println!("交换前: a = {}, b = {}", a, b);

    // 使用元组交换（无需临时变量）
    (a, b) = (b, a);
    println!("交换后: a = {}, b = {}", a, b);
}
```

## 今日总结

- [ ] `let` 声明不可变变量，`let mut` 声明可变变量
- [ ] `shadowing` 可以重新绑定同名变量，甚至改变类型
- [ ] `const` 声明编译期常量，必须标注类型
- [ ] 整数默认 `i32`，浮点默认 `f64`
- [ ] 整数溢出在 debug 模式 panic，release 模式环绕
- [ ] 元组 `(T1, T2)` 可以存放不同类型，用 `.0`、`.1` 访问
- [ ] 数组 `[T; N]` 固定长度，元素同类型，越界访问会 panic
- [ ] 切片 `&[T]` 是数组/向量的引用片段

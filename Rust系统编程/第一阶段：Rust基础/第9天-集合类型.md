## 1. Vector

### 创建 Vector

```rust
fn main() {
    // 空 vector
    let v1: Vec<i32> = Vec::new();

    // 使用宏创建（常用）
    let v2 = vec![1, 2, 3];

    // 指定容量
    let mut v3 = Vec::with_capacity(10);
}
```

### 添加元素

```rust
fn main() {
    let mut v = Vec::new();

    v.push(1);
    v.push(2);
    v.push(3);

    println!("{:?}", v);  // [1, 2, 3]
}
```

### 读取元素

```rust
fn main() {
    let v = vec![1, 2, 3, 4, 5];

    // 索引访问（越界会 panic）
    let third = v[2];
    println!("第三个元素: {}", third);

    // get 方法（越界返回 None）
    match v.get(2) {
        Some(n) => println!("第三个: {}", n),
        None => println!("没有第三个"),
    }

    // 安全的越界访问
    if let Some(n) = v.get(100) {
        println!("{}", n);
    } else {
        println!("索引 100 越界");
    }
}
```

### 所有权问题

```rust
fn main() {
    let v = vec![
        String::from("hello"),
        String::from("world"),
    ];

    // let s = v[0];     // ❌ 错误！不能移动出 vector
    let s = &v[0];       // ✅ 借用
    println!("{}", s);

    // v.push(String::from("!"));  // ❌ 错误！已有不可变引用
    println!("vector: {:?}", v);
}
```

### 遍历

```rust
fn main() {
    let v = vec![100, 32, 57];

    // 不可变遍历
    for i in &v {
        println!("{}", i);
    }

    // 可变遍历
    let mut v = vec![100, 32, 57];
    for i in &mut v {
        *i += 50;  // 解引用修改
    }
    println!("{:?}", v);  // [150, 82, 107]
}
```

### 存储枚举变体


## 2. HashMap

### 创建

```rust
use std::collections::HashMap;

fn main() {
    // 空 HashMap
    let mut scores = HashMap::new();

    // 插入
    scores.insert(String::from("Blue"), 10);
    scores.insert(String::from("Yellow"), 50);
}
```

### 从 Vector 创建

```rust
fn main() {
    let teams = vec![String::from("Blue"), String::from("Yellow")];
    let initial_scores = vec![10, 50];

    let scores: HashMap<_, _> =
        teams.into_iter().zip(initial_scores.into_iter()).collect();
}
```

### 访问

```rust
fn main() {
    let mut scores = HashMap::new();
    scores.insert("Blue".to_string(), 10);

    // get
    let blue_score = scores.get("Blue");   // Some(&10)
    let red_score = scores.get("Red");     // None

    // 循环
    for (key, value) in &scores {
        println!("{}: {}", key, value);
    }
}
```

### 更新

```rust
fn main() {
    let mut scores = HashMap::new();

    // 直接插入（覆盖）
    scores.insert("Blue", 10);
    scores.insert("Blue", 25);  // 覆盖

    // 只在 key 不存在时插入
    scores.entry("Yellow").or_insert(50);
    scores.entry("Blue").or_insert(50);  // 已有 Blue，不插入

    // 基于旧值更新
    let text = "hello world wonderful world";
    let mut map = HashMap::new();
    for word in text.split_whitespace() {
        let count = map.entry(word).or_insert(0);
        *count += 1;
    }
    println!("{:?}", map);
    // {"world": 2, "wonderful": 1, "hello": 1}
}
```

## 3. String（复习与深入）

### String 与 &str

```rust
fn main() {
    // String：拥有所有权，可增长，堆分配
    let mut s = String::from("hello");
    s.push_str(", world");

    // &str：字符串切片，借用
    let s2 = "hello";  // 类型是 &str
}
```

### 常用方法

```rust
fn main() {
    let mut s = String::from("foo");

    s.push('!');           // 添加字符
    s.push_str(" bar");    // 添加字符串

    let s2 = s + " baz";   // 注意：s 被移动了

    let s1 = String::from("Hello, ");
    let s2 = String::from("world!");
    let s3 = s1 + &s2;     // s1 被移动，s2 被借用
}
```

### format! 宏

```rust
fn main() {
    let s1 = String::from("tic");
    let s2 = String::from("tac");
    let s3 = String::from("toe");

    let s = format!("{}-{}-{}", s1, s2, s3);
    // s1, s2, s3 仍可用（不获取所有权）
}
```

### 索引与遍历

```rust
fn main() {
    let s = String::from("hello");
    // let h = s[0];  // ❌ 错误！String 不支持索引

    // 按字节切片
    let hello = &s[0..2];  // "he"（仅 ASCII 安全）

    // 安全遍历
    for c in s.chars() {
        println!("{}", c);  // h e l l o
    }

    for b in s.bytes() {
        println!("{}", b);  // 104 101 108 108 111
    }
}
```

⚠️ Rust 字符串是 UTF-8，一个字符可能占多个字节，所以不能直接索引。

## 4. 其他集合

### HashSet

```rust
use std::collections::HashSet;

fn main() {
    let mut set = HashSet::new();

    set.insert(1);
    set.insert(2);
    set.insert(2);  // 重复，不插入

    println!("{:?}", set);  // {1, 2}

    // 集合运算
    let a: HashSet<i32> = [1, 2, 3].iter().cloned().collect();
    let b: HashSet<i32> = [2, 3, 4].iter().cloned().collect();

    println!("交集: {:?}", a.intersection(&b).collect::<Vec<_>>());
    println!("并集: {:?}", a.union(&b).collect::<Vec<_>>());
}
```

### VecDeque

```rust
use std::collections::VecDeque;

fn main() {
    let mut deque = VecDeque::new();

    deque.push_back(1);   // 尾部添加
    deque.push_front(0);  // 头部添加

    let front = deque.pop_front();  // Some(0)
    let back = deque.pop_back();    // Some(1)
}
```

## 实战练习

### 练习 1：统计字符频率

```rust
use std::collections::HashMap;

fn char_frequency(text: &str) -> HashMap<char, usize> {
    let mut map = HashMap::new();

    for c in text.chars() {
        if c.is_alphabetic() {
            let count = map.entry(c.to_lowercase().next().unwrap()).or_insert(0);
            *count += 1;
        }
    }

    map
}

fn main() {
    let text = "Hello, World! Hello, Rust!";
    let freq = char_frequency(text);

    let mut pairs: Vec<_> = freq.iter().collect();
    pairs.sort_by(|a, b| b.1.cmp(a.1));  // 按频率降序

    for (c, count) in pairs {
        println!("'{}': {}", c, count);
    }
}
```

### 练习 2：学生成绩管理

```rust
use std::collections::HashMap;

struct Student {
    name: String,
    scores: HashMap<String, f32>,
}

impl Student {
    fn new(name: &str) -> Student {
        Student {
            name: String::from(name),
            scores: HashMap::new(),
        }
    }

    fn add_score(&mut self, subject: &str, score: f32) {
        self.scores.insert(String::from(subject), score);
    }

    fn average(&self) -> f32 {
        if self.scores.is_empty() {
            return 0.0;
        }
        let sum: f32 = self.scores.values().sum();
        sum / self.scores.len() as f32
    }

    fn best_subject(&self) -> Option<(&String, &f32)> {
        self.scores.iter().max_by(|a, b| a.1.partial_cmp(b.1).unwrap())
    }
}

fn main() {
    let mut alice = Student::new("Alice");
    alice.add_score("Math", 95.0);
    alice.add_score("English", 88.0);
    alice.add_score("Science", 92.0);

    println!("{} 平均分: {:.1}", alice.name, alice.average());

    if let Some((subject, score)) = alice.best_subject() {
        println!("最高分: {} ({})", subject, score);
    }
}
```

### 练习 3：去重并保持顺序

```rust
use std::collections::HashSet;

fn dedup_ordered<T: Clone + Eq + std::hash::Hash>(items: &[T]) -> Vec<T> {
    let mut seen = HashSet::new();
    let mut result = Vec::new();

    for item in items {
        if seen.insert(item.clone()) {
            result.push(item.clone());
        }
    }

    result
}

fn main() {
    let nums = vec![1, 2, 3, 2, 4, 3, 5, 1];
    let unique = dedup_ordered(&nums);
    println!("{:?}", unique);  // [1, 2, 3, 4, 5]
}
```

## 今日总结

- [ ] `Vec<T>` 动态数组，`vec![]` 宏快速创建
- [ ] `HashMap<K, V>` 键值对存储，`entry().or_insert()` 简洁更新
- [ ] `HashSet<T>` 去重集合，支持交集、并集等运算
- [ ] `VecDeque<T>` 双端队列，`BTreeMap/BTreeSet` 有序版本
- [ ] Vector 中的值被移动后原位置失效
- [ ] String 不能索引，因为 UTF-8 字符长度不固定
- [ ] `chars()` 遍历 Unicode 字符，`bytes()` 遍历字节
- [ ] `format!` 不获取所有权，比 `+` 拼接更安全

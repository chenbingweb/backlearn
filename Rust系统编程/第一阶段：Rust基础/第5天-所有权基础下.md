## 1. 引用与借用

### 为什么需要引用

回顾昨天的问题：
```rust
fn main() {
    let s = String::from("hello");
    let (s, len) = calculate_length(s);  // 传递 + 返回，很麻烦
    println!("{} 长度: {}", s, len);
}

fn calculate_length(s: String) -> (String, usize) {
    (s, s.len())
}
```

### 使用引用

```rust
fn main() {
    let s = String::from("hello");
    let len = calculate_length(&s);  // 传递引用，不转移所有权

    println!("'{}' 长度是 {}", s, len);  // ✅ s 仍可用
}

fn calculate_length(s: &String) -> usize {
    s.len()
} // s 是引用，不拥有值，不释放内存
```

```
main: s ──→ 堆: "hello"
        ↓
calculate_length: &s ──→ 借用（不拥有）
```

### 借用规则

1. **同一时间可以有多个不可变引用**
2. **同一时间只能有一个可变引用**
3. **不能同时有不可变引用和可变引用**

---

## 2. 不可变引用

```rust
fn main() {
    let s = String::from("hello");

    let r1 = &s;
    let r2 = &s;       // ✅ 多个不可变引用

    println!("{} {}", r1, r2);
}
```

### 尝试修改引用指向的值

```rust
fn main() {
    let s = String::from("hello");
    change(&s);  // ❌ 错误！
}

fn change(s: &String) {
    s.push_str(", world");  // 不可变引用不能修改
}
```

---

## 3. 可变引用

```rust
fn main() {
    let mut s = String::from("hello");
    change(&mut s);    // 传递可变引用
    println!("{}", s); // hello, world
}

fn change(s: &mut String) {
    s.push_str(", world");
}
```

### 可变引用的限制

```rust
fn main() {
    let mut s = String::from("hello");

    let r1 = &mut s;
    let r2 = &mut s;   // ❌ 错误！只能有一个可变引用

    println!("{}, {}", r1, r2);
}
```

为什么？防止**数据竞争**：
- 两个指针同时访问同一数据
- 至少有一个在写入
- 没有同步机制

### 不可变 + 可变 不能共存

```rust
fn main() {
    let mut s = String::from("hello");

    let r1 = &s;       // 不可变引用
    let r2 = &mut s;   // ❌ 错误！已有不可变引用

    println!("{}, {}", r1, r2);
}
```

### 引用的作用域

```rust
fn main() {
    let mut s = String::from("hello");

    {
        let r1 = &s;
        println!("{}", r1);  // r1 在这里使用
    }   // r1 的作用域结束

    let r2 = &mut s;       // ✅ 现在可以了
    println!("{}", r2);
}
```

## 4. 切片 Slice

### 字符串切片

```rust
fn main() {
    let s = String::from("hello world");

    let hello = &s[0..5];    // 从开始到索引 5（不含）
    let world = &s[6..11];   // 索引 6 到 11（不含）

    // 简化写法
    let hello2 = &s[..5];    // 从开始
    let world2 = &s[6..];    // 到结束
    let whole = &s[..];      // 全部

    println!("{} {}", hello, world);
}
```

### 切片的类型

```rust
fn main() {
    let s = String::from("hello");

    let slice1: &str = &s[0..2];      // 字符串切片
    let slice2 = &s[..];               // 类型推断为 &str
}
```

### 数组切片

```rust
fn main() {
    let a = [1, 2, 3, 4, 5];
    let slice = &a[1..3];  // [2, 3]

    assert_eq!(slice, &[2, 3]);
}
```

### 切片作为函数参数

```rust
fn main() {
    let s = String::from("hello world");
    let word = first_word(&s);
    println!("第一个单词: {}", word);
}

// 接受 &String 或 &str
fn first_word(s: &str) -> &str {
    let bytes = s.as_bytes();

    for (i, &item) in bytes.iter().enumerate() {
        if item == b' ' {
            return &s[0..i];
        }
    }

    &s[..]
}
```

使用 `&str` 的好处：
- 可以接受 `String` 的引用
- 也可以接受字符串字面量 `"hello"`（本身就是 `&str`）

## 5. 悬垂引用

### 编译器阻止悬垂引用

```rust
fn main() {
    let reference_to_nothing = dangle();
}

fn dangle() -> &String {    // ❌ 错误！
    let s = String::from("hello");
    &s
} // s 离开作用域被释放，返回的引用指向无效内存
```

编译器错误：
```
error[E0106]: missing lifetime specifier
```

### 正确做法：转移所有权

```rust
fn no_dangle() -> String {
    let s = String::from("hello");
    s  // 转移所有权出去
}

fn main() {
    let s = no_dangle();  // ✅
    println!("{}", s);
}
```

## 6. 所有权与引用总结

```
所有权转移：
  let s1 = String::from("hi");
  let s2 = s1;           // s1 → s2，s1 失效

不可变借用：
  let r = &s;            // 可以多个，只读

可变借用：
  let r = &mut s;        // 只能一个，可读写

切片借用：
  let slice = &s[0..5];  // 不可变借用的一种
```

规则速查表：

| 场景 | 允许？ |
|------|--------|
| 多个 `&T` | ✅ |
| 多个 `&mut T` | ❌ |
| `&T` + `&mut T` | ❌ |
| `&mut T`，前一个已不用 | ✅ |

## 实战练习

### 练习 1：修改字符串

```rust
fn main() {
    let mut s = String::from("hello");
    append_world(&mut s);
    println!("{}", s);
}

fn append_world(s: &mut String) {
    s.push_str(" world!");
}
```

### 练习 2：找出最大数（切片）

```rust
fn main() {
    let numbers = [34, 50, 25, 100, 65];
    let largest = find_largest(&numbers);
    println!("最大数是 {}", largest);
}

fn find_largest(numbers: &[i32]) -> i32 {
    let mut largest = numbers[0];

    for &number in numbers {
        if number > largest {
            largest = number;
        }
    }

    largest
}
```

### 练习 3：字符串截取

```rust
fn main() {
    let s = String::from("The quick brown fox");
    println!("第一个单词: '{}'", first_word(&s));
}

fn first_word(s: &str) -> &str {
    for (i, c) in s.chars().enumerate() {
        if c == ' ' {
            return &s[..i];
        }
    }
    s
}
```

### 练习 4：判断以下代码

```rust
fn main() {
    let mut s = String::from("hello");
    let r1 = &s;
    let r2 = &s;
    println!("{} {}", r1, r2);
    let r3 = &mut s;  // ?
    println!("{}", r3);
}
```

答案：✅ 可以编译！因为 r1 和 r2 的最后一次使用在 `println!` 之后，之后不再使用，所以可变借用的范围不冲突。

## 今日总结

- [ ] `&T` 是不可变引用（借用），不转移所有权
- [ ] `&mut T` 是可变引用，允许修改数据
- [ ] 可以同时有多个不可变引用，但只能有一个可变引用
- [ ] 不能同时有不可变引用和可变引用
- [ ] 引用必须始终有效（编译器防止悬垂引用）
- [ ] 切片 `&[T]` 或 `&str` 是对集合/字符串部分的引用
- [ ] 函数参数优先用 `&str` 而不是 `&String`，更灵活
- [ ] 借用规则在编译期检查，零运行时开销

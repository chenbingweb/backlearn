## 1. 结构体中的生命周期

### 包含引用的结构体

```rust
// 结构体持有引用时，必须声明生命周期参数
struct ImportantExcerpt<'a> {
    part: &'a str,
}

fn main() {
    let novel = String::from("Call me Ishmael. Some years ago...");
    let first_sentence = novel.split('.').next().unwrap();

    // excerpt 的生命周期不能超过 first_sentence
    let excerpt = ImportantExcerpt {
        part: first_sentence,
    };

    println!("excerpt: {}", excerpt.part);
}  // excerpt 先释放，然后 novel 释放
```

### 多个生命周期

```rust
struct Message<'a, 'b> {
    from: &'a str,
    to: &'b str,
    content: String,  // 拥有的数据，不需要生命周期
}

fn main() {
    let from_name = "Alice";
    {
        let to_name = "Bob";
        let msg = Message {
            from: from_name,
            to: to_name,
            content: String::from("Hello!"),
        };
        println!("{} -> {}: {}", msg.from, msg.to, msg.content);
    }  // msg 释放，但 from_name 仍可用
}
```

### 生命周期与字段类型

```rust
struct BorrowedOrOwned<'a> {
    // 可能借用，可能拥有
    data: Cow<'a, str>,
}

use std::borrow::Cow;

fn main() {
    // 借用
    let s = String::from("hello");
    let _b1 = BorrowedOrOwned { data: Cow::Borrowed(&s) };

    // 拥有
    let _b2 = BorrowedOrOwned { data: Cow::Owned(String::from("world")) };
}
```

## 2. 生命周期省略进阶

### 静态方法中的生命周期

```rust
struct Person<'a> {
    name: &'a str,
}

impl<'a> Person<'a> {
    // 不需要额外标注（规则3）
    fn get_name(&self) -> &str {
        self.name
    }

    // 静态方法：没有 self，必须显式标注
    fn create_greeting(name: &str) -> String {
        format!("Hello, {}!", name)
    }
}
```

### 多个引用参数的处理

```rust
struct Parser<'a> {
    text: &'a str,
}

impl<'a> Parser<'a> {
    // 返回值和 &self 生命周期相同（规则3）
    fn parse(&self) -> Result<&'a str, String> {
        Ok(&self.text[0..5])
    }

    // 需要显式标注：返回和参数的关系
    fn find<'b>(&self, pattern: &'b str) -> Option<&'a str> {
        self.text.find(pattern).map(|i| &self.text[i..i+pattern.len()])
    }
}
```

## 3. 生命周期边界

### 泛型 + 生命周期边界

```rust
// T 必须实现 Display，且引用至少存活 'a
fn print_ref<'a, T>(x: &'a T)
where
    T: std::fmt::Display + 'a,  // T 自身也可能包含引用
{
    println!("{}", x);
}
```

### `'a: 'b` 子类型关系

`'a: 'b` 表示 "`'a` 至少和 `'b` 一样长"（`'a` outlives `'b`）：

```rust
// 'outer 必须比 'inner 更长
fn nested_refs<'outer, 'inner>(outer: &'outer str, inner: &'inner str)
where
    'outer: 'inner,  // 'outer 至少和 'inner 一样长
{
    println!("outer: {}, inner: {}", outer, inner);
}
```

### 实际应用

```rust
struct Config<'a> {
    settings: &'a HashMap<String, String>,
}

// 确保返回的引用和 Config 生命周期一致
impl<'a> Config<'a> {
    fn get(&self, key: &str) -> Option<&'a str> {
        self.settings.get(key).map(|s| s.as_str())
    }
}

use std::collections::HashMap;

fn main() {
    let mut map = HashMap::new();
    map.insert(String::from("host"), String::from("localhost"));

    let config = Config { settings: &map };
    println!("host: {:?}", config.get("host"));
}
```

## 4. Self 引用问题

### 无法直接创建自引用结构体

```rust
// ❌ 以下代码无法编译
struct SelfReferential<'a> {
    data: String,
    pointer: &'a str,  // 试图引用 data
}

fn main() {
    let mut s = SelfReferential {
        data: String::from("hello"),
        pointer: "",  // 临时值
    };
    s.pointer = &s.data;  // ❌ 编译器无法验证生命周期
}
```

### 解决方案

**方案1：使用索引代替引用**

```rust
struct Better {
    data: String,
    start: usize,  // 用索引代替引用
    end: usize,
}

impl Better {
    fn get_slice(&self) -> &str {
        &self.data[self.start..self.end]
    }
}
```

**方案2：使用 Pin + 不安全代码**（高级）

```rust
use std::pin::Pin;

// 需要 unsafe，后续阶段学习
```

**方案3：使用现成的 crate**

```toml
[dependencies]
owning_ref = "0.4"
rental = "0.5"
```

## 5. 高阶 Trait Bound

### `for<'a>` 语法

```rust
// 接受一个闭包，闭包可以接受任意生命周期的引用
fn with_callback<F>(callback: F)
where
    F: for<'a> Fn(&'a str) -> usize,  // 对任意 'a 都成立
{
    let s = String::from("hello");
    callback(&s);
}

fn main() {
    with_callback(|s| s.len());
}
```

## 6. 生命周期思维模型

### 分析步骤

遇到生命周期问题时，按以下步骤思考：

1. **找出所有引用**：哪些变量是引用？
2. **确定所有权关系**：谁拥有数据？谁只是借用？
3. **标注生命周期**：返回值的生命周期和哪个输入参数关联？
4. **验证约束**：确保没有引用比数据活得更长

### 常见模式

```
模式1：输入输出同生命周期
    fn foo<'a>(x: &'a T) -> &'a U

模式2：多个输入，取最短
    fn foo<'a>(x: &'a T, y: &'a T) -> &'a U

模式3：独立生命周期
    fn foo<'a, 'b>(x: &'a T, y: &'b T) -> &'a U

模式4：返回不依赖引用
    fn foo(x: &T) -> OwnedType
```

## 实战练习

### 练习 1：实现一个简单的解析器

```rust
struct LineParser<'a> {
    content: &'a str,
    position: usize,
}

impl<'a> LineParser<'a> {
    fn new(content: &'a str) -> LineParser<'a> {
        LineParser { content, position: 0 }
    }

    fn next_token(&mut self) -> Option<&'a str> {
        let remaining = &self.content[self.position..];
        let mut chars = remaining.char_indices();

        // 跳过空白
        let start = loop {
            match chars.next() {
                Some((i, c)) if c.is_whitespace() => continue,
                Some((i, _)) => break i,
                None => return None,
            }
        };

        // 找到下一个空白
        let end = loop {
            match chars.next() {
                Some((i, c)) if c.is_whitespace() => break i,
                Some(_) => continue,
                None => break remaining.len(),
            }
        };

        self.position += end;
        Some(&remaining[start..end])
    }
}

fn main() {
    let text = "hello world foo bar";
    let mut parser = LineParser::new(text);

    while let Some(token) = parser.next_token() {
        println!("token: {}", token);
    }
}
```

### 练习 2：字符串搜索工具

```rust
struct SearchResult<'a, 'b> {
    text: &'a str,
    pattern: &'b str,
    position: usize,
}

fn search<'a, 'b>(text: &'a str, pattern: &'b str) -> Vec<SearchResult<'a, 'b>> {
    let mut results = Vec::new();
    let mut start = 0;

    while let Some(pos) = text[start..].find(pattern) {
        let absolute_pos = start + pos;
        results.push(SearchResult {
            text: &text[absolute_pos..absolute_pos + pattern.len()],
            pattern,
            position: absolute_pos,
        });
        start = absolute_pos + 1;
    }

    results
}

fn main() {
    let text = "The quick brown fox jumps over the lazy dog. The fox was quick.";
    let results = search(text, "fox");

    for r in results {
        println!("在位置 {} 找到 '{}'", r.position, r.text);
    }
}
```

### 练习 3：生命周期判断

```rust
struct Wrapper<'a> {
    value: &'a str,
}

impl<'a> Wrapper<'a> {
    fn get(&self) -> &str {
        self.value
    }
}

fn main() {
    let data = String::from("hello");
    let wrapper;
    {
        let inner = data.as_str();
        wrapper = Wrapper { value: inner };
        println!("{}", wrapper.get());  // ?
    }                                    // inner 释放
    println!("{}", wrapper.get());      // ?
}
```

答案：✅ 两句都能编译！因为 `inner` 只是 `data` 的引用，`data` 在 main 结束才释放。`inner` 变量被释放不影响引用本身。

## 今日总结

- [ ] 持有引用的结构体必须声明生命周期参数
- [ ] `impl<'a> Struct<'a>` 为带生命周期的结构体实现方法
- [ ] 多条生命周期参数可以独立标注
- [ ] `'a: 'b` 表示 `'a` 至少和 `'b` 一样长（outlives）
- [ ] 自引用结构体不能直接用引用，用索引或 unsafe 解决
- [ ] `for<'a>` 高阶 Trait Bound 表示对所有生命周期成立
- [ ] 分析生命周期：找出引用 → 确定所有权 → 标注 → 验证

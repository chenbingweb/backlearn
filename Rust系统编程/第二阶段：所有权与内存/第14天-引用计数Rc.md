## 1. 为什么需要 Rc

### Box 的限制

```rust
enum List {
    Cons(i32, Box<List>),
    Nil,
}

use List::{Cons, Nil};

fn main() {
    let a = Cons(5, Box::new(Cons(10, Box::new(Nil))));
    let b = Cons(3, Box::new(a));  // a 被移动
    // let c = Cons(4, Box::new(a));  // ❌ a 已被移动！
}
```

### Rc 解决共享所有权

```rust
enum List {
    Cons(i32, Rc<List>),
    Nil,
}

use List::{Cons, Nil};
use std::rc::Rc;

fn main() {
    let a = Rc::new(Cons(5, Rc::new(Cons(10, Rc::new(Nil)))));

    println!("创建 a 后的引用计数: {}", Rc::strong_count(&a));

    let b = Cons(3, Rc::clone(&a));  // 引用计数 +1
    println!("创建 b 后的引用计数: {}", Rc::strong_count(&a));

    {
        let c = Cons(4, Rc::clone(&a));  // 引用计数 +1
        println!("创建 c 后的引用计数: {}", Rc::strong_count(&a));
    }  // c 离开作用域，引用计数 -1

    println!("c 释放后的引用计数: {}", Rc::strong_count(&a));
}
```

输出：
```
创建 a 后的引用计数: 1
创建 b 后的引用计数: 2
创建 c 后的引用计数: 3
c 释放后的引用计数: 2
```

## 2. Rc 的核心特性

### 不可变共享

```rust
use std::rc::Rc;

fn main() {
    let data = Rc::new(String::from("共享数据"));

    let data2 = Rc::clone(&data);
    let data3 = Rc::clone(&data);

    // 所有引用都指向同一个数据
    println!("data: {}", data);
    println!("data2: {}", data2);
    println!("data3: {}", data3);

    // data.push_str("!");  // ❌ Rc 是不可变的
}
```

### Rc::clone vs 普通 clone

```rust
use std::rc::Rc;

fn main() {
    let data = Rc::new(vec![1, 2, 3]);

    // Rc::clone 只增加引用计数，不复制数据（廉价）
    let data2 = Rc::clone(&data);

    // .clone() 会深拷贝数据（昂贵）
    // let data3 = data.clone();  // 一般不这样做
}
```

`Rc::clone(&data)` 的代价：只是递增一个整数。

### 获取引用计数

```rust
use std::rc::Rc;

fn main() {
    let rc = Rc::new(42);

    println!("引用计数: {}", Rc::strong_count(&rc));
    println!("弱引用计数: {}", Rc::weak_count(&rc));
}
```

## 3. Rc 的约束

### 单线程限制

```rust
use std::rc::Rc;
use std::thread;

fn main() {
    let data = Rc::new(42);

    // thread::spawn(move || {
    //     println!("{}", data);  // ❌ Rc 不能跨线程！
    // });
}
```

`Rc<T>` 没有实现 `Send` Trait，不能在线程间转移。

多线程共享所有权用 `Arc<T>`（下一节）。

### 不可变性限制

```rust
use std::rc::Rc;

fn main() {
    let data = Rc::new(42);

    // *data += 1;  // ❌ Rc 不可变
}
```

需要内部可变性用 `Rc<RefCell<T>>`（下一节）。

## 4. Rc 的内部实现

### 内存布局

```
堆上的 RcBox:
┌─────────────┐
│ strong: 2   │  ← 强引用计数
│ weak: 0     │  ← 弱引用计数
│─────────────│
│ value: T    │  ← 实际数据
└─────────────┘
```

### 释放时机

- **强引用计数为 0**：释放 `value` 和 `strong`/`weak` 计数器
- **弱引用计数为 0**：释放计数器内存

```rust
use std::rc::Rc;

fn main() {
    let a = Rc::new(String::from("hello"));
    let b = Rc::downgrade(&a);  // 弱引用

    println!("强引用: {}", Rc::strong_count(&a));  // 1
    println!("弱引用: {}", Rc::weak_count(&a));    // 1

    // 通过弱引用访问
    if let Some(upgrade) = b.upgrade() {
        println!("通过弱引用: {}", upgrade);
    }
}
```

弱引用用于打破循环引用：

```rust
use std::rc::{Rc, Weak};
use std::cell::RefCell;

struct Node {
    value: i32,
    parent: RefCell<Weak<Node>>,      // 弱引用，避免循环
    children: RefCell<Vec<Rc<Node>>>, // 强引用
}

fn main() {
    let leaf = Rc::new(Node {
        value: 3,
        parent: RefCell::new(Weak::new()),
        children: RefCell::new(vec![]),
    });

    println!("leaf 父节点 = {:?}", leaf.parent.borrow().upgrade());

    let branch = Rc::new(Node {
        value: 5,
        parent: RefCell::new(Weak::new()),
        children: RefCell::new(vec![Rc::clone(&leaf)]),
    });

    *leaf.parent.borrow_mut() = Rc::downgrade(&branch);

    println!("leaf 父节点 = {:?}", leaf.parent.borrow().upgrade());
}
```

## 5. Rc 与 Box 对比

| 特性 | Box<T> | Rc<T> |
|------|--------|-------|
| 所有权 | 唯一 | 共享 |
| 可变 | 是 | 否（默认）|
| 线程安全 | 否（Send）| 否 |
| 运行时开销 | 无 | 引用计数 |
| 释放时机 | 离开作用域 | 计数为0 |

## 6. Rc 使用场景

### 场景1：共享配置

```rust
use std::rc::Rc;

#[derive(Debug)]
struct Config {
    host: String,
    port: u16,
}

fn main() {
    let config = Rc::new(Config {
        host: String::from("localhost"),
        port: 8080,
    });

    // 多个组件共享配置
    let server_config = Rc::clone(&config);
    let client_config = Rc::clone(&config);

    println!("server: {:?}", server_config);
    println!("client: {:?}", client_config);
}
```

### 场景2：有向无环图（DAG）

```rust
use std::rc::Rc;

#[derive(Debug)]
struct File {
    name: String,
}

#[derive(Debug)]
struct Folder {
    name: String,
    files: Vec<Rc<File>>,
}

fn main() {
    let file = Rc::new(File {
        name: String::from("shared.txt"),
    });

    let folder1 = Folder {
        name: String::from("docs"),
        files: vec![Rc::clone(&file)],
    };

    let folder2 = Folder {
        name: String::from("backup"),
        files: vec![Rc::clone(&file)],
    };

    println!("file 引用计数: {}", Rc::strong_count(&file));
}
```

## 实战练习

### 练习 1：实现共享的链表

```rust
use std::rc::Rc;

#[derive(Debug)]
enum List {
    Cons(i32, Rc<List>),
    Nil,
}

use List::{Cons, Nil};

fn main() {
    let a = Rc::new(Cons(5, Rc::new(Cons(10, Rc::new(Nil)))));
    println!("a 创建后计数: {}", Rc::strong_count(&a));

    let b = Cons(3, Rc::clone(&a));
    println!("b 创建后计数: {}", Rc::strong_count(&a));

    let c = Cons(4, Rc::clone(&a));
    println!("c 创建后计数: {}", Rc::strong_count(&a));

    println!("a: {:?}", a);
    println!("b: {:?}", b);
    println!("c: {:?}", c);
}
```

### 练习 2：实现简单的引用计数容器

```rust
use std::rc::Rc;

struct SharedData {
    name: String,
    data: Vec<i32>,
}

impl SharedData {
    fn new(name: &str) -> SharedData {
        SharedData {
            name: String::from(name),
            data: Vec::new(),
        }
    }

    fn info(&self) {
        println!("{}: {:?}", self.name, self.data);
    }
}

fn main() {
    let shared = Rc::new(SharedData::new("共享数据"));

    let s1 = Rc::clone(&shared);
    let s2 = Rc::clone(&shared);

    println!("引用计数: {}", Rc::strong_count(&shared));

    s1.info();
    s2.info();
}
```

### 练习 3：判断输出

```rust
use std::rc::Rc;

fn main() {
    let a = Rc::new(5);
    let b = Rc::clone(&a);
    let c = Rc::clone(&a);

    println!("{}", Rc::strong_count(&a));

    {
        let d = Rc::clone(&a);
        println!("{}", Rc::strong_count(&a));
    }

    println!("{}", Rc::strong_count(&a));
}
```

答案：3、4、3

## 今日总结

- [ ] `Rc<T>` 实现共享所有权，单线程使用
- [ ] `Rc::clone(&rc)` 增加引用计数，不复制数据
- [ ] 当强引用计数为 0 时，数据被释放
- [ ] `Weak<T>` 弱引用不阻止释放，用于打破循环引用
- [ ] Rc 默认不可变，多线程用 `Arc`，可变用 `RefCell`
- [ ] `Rc` 不实现 `Send`，不能跨线程传递
- [ ] 适用于：共享配置、DAG 数据结构、缓存
